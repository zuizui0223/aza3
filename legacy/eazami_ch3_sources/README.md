# Legacy EAzami prospective Chapter 3 sources

This directory preserves source material that historically lived in EAzami but belongs conceptually to prospective Chapter 3 execution.

## Authority rule

Nothing under this directory is an active sampling, sequencing, manipulation or claim contract.

Current authority lives in the aza3 root/docs/data planning layers, especially:

- `docs/CHAPTER3_MASTER_SAMPLE_LIST_V11.md`;
- `data/planning/chapter3_master_sample_blocks_v11.csv`;
- `data/planning/chapter3_master_sample_summary_v11.json`;
- P01-P05 / P02-native contracts;
- M01 operational ledgers;
- v7/v10 nationwide tree/conservation contracts.

## What was migrated

The archive contains the prospective EAzami material needed to reconstruct how the current aza3 designs arose, including:

- old field/sample ID conventions;
- old cross-Aim individual and population manifests;
- Aim2 field, bout, orientation, display/predation, assurance/antagonist and recruitment ledger schemas;
- old fixed-white / Japan-wide / RAD sampling panels;
- old Phase-A population targets;
- JPN36 PR #114 contract/schema/validation source material.

These old sample counts (`core190`, 222, 298, broad Taiwan/China panels, etc.) are explicitly non-authoritative.

## Why not duplicate every old executable file

EAzami remains a preserved public provenance repository. Historical validators/randomizers/workflows that are not used by current aza3 are referenced by their immutable source PR/commit rather than maintained as a second executable copy here. This avoids two dormant implementations drifting while preserving exact reproducibility at the original source.

Key immutable source anchors include:

- EAzami PR #114, head `4ca5c1f62147158aa8bbace97a86cd91526acf34` — JPN36 phyllary-access pilot;
- EAzami PR #155, head `b3f91d98952b4f04bd27282e33d31b80694e248a` — old P01-labelled JPN06/JPN15 RAD contract, migrated to aza3 P02;
- EAzami Issue #154 — Chapter 2→3 stickiness handoff;
- EAzami Issue #27 — former doctoral execution issue, closed after migration to aza3 #11.

Where a source concept remains active, aza3 has an aza3-native replacement rather than executing the legacy file directly.

## Sensitive locality rule

Some historical schemas contained latitude/longitude fields. They are retained only as legacy schema provenance. Current aza3 public manifests prohibit exact coordinates and rare-species micro-locality directions; exact sites belong in a private field ledger.

## Migration status

As of 2026-09-04, prospective biological execution ownership is fully on aza3. EAzami is the Chapter 2 public-evidence/provenance source and does not contain an active doctoral field/RAD/molecular execution mainline.
