# Q2で得られた別種ではなく同種の強い比較：Cirsium purpuratum の送粉・種子食害ディスプレイ応答

**2026-10-19 | aza3 PR #50 | 1998/2000の公刊された野外実験を一次文献の式・生物種・計測方法で監査した源データ再表現。** 個体データの再推定ではなく、**原著回帰係数からの数学的再計算**。

## 実際に公刊されている同一種の生態学

**送粉側 — Ohashi & Yahara (1998)** [DOI 10.2307/2446309](https://doi.org/10.2307/2446309), *American Journal of Botany* 85:219–224:

- `Cirsium purpuratum` の人工的な花頭ディスプレイ配置を使い、日ごとにLatin squareで対象植物を入れ替えてマルハナバチ訪問を記録した。
- 植物当たりの訪問頻度は花頭ディスプレイが大きいほど**増えるが逓減**、1回の採餌で訪問する頭花数はディスプレイとともに増加。
- これら二応答からモデル化した**頭花当たり訪問率は、同日内では花頭数にほぼ依存せず一定**。これは「受粉があった」「花粉沈着が増えた」「成熟痩果が増えた」という実証ではなく、訪花行動の結果。

**敵側 — Ohashi & Yahara (2000)** [DOI 10.1139/b99-182](https://doi.org/10.1139/b99-182), *Canadian Journal of Botany* 78:230–236:

- *C. purpuratum* の種子食者は **`Larinus meleagris`（ゾウムシ）と`Delia platula`（ハエ）**。二種の寄与を区別しており、単なる「害虫」ひとくくりではない。
- 栃木県**日光**1993年（母植物13個体）：成熟頭花を解剖し、種子食被害割合を直接測定した。幼虫の種組成は`Larinus`44%、`Delia`56%。頭花食害成立90.8%、幼虫数平均5.4/頭花。
- 栃木県**川俣**1994年（母植物27個体）：幼虫の構成は`Larinus`84%、`Delia`16%。食害成立31.3%、幼虫数平均0.26/頭花。**重要：ここでの種子損失割合は直接観察ではなく、1頭花に幼虫1匹以下／頭花当たり451小花／幼虫当たり52種子食という日光値の借用から推定した**。川俣の数を日光と同じ品質の実測種子損失と誤記しない。

公刊された花数 F（植物が一生殖季節に生産する**小花の総数**）と植物当たり種子被害割合 Pr の飽和回帰は、両地点で

`Pr(F)=1-exp(-aF)`

として報告された。**F は頭花の向き、粘着性、真のトゲ長や総苞の隙間ではない。**

## 公刊係数をそのまま再計算した量

| 著者による元の回帰 | 日光（1993、n=13） | 川俣（1994、n=27） |
|---|---:|---:|
| 飽和式 a（/小花） | **0.000063** | **0.0000075** |
| 元論文の各地点内フィット R² | 0.44 | 0.26 |
| 元論文の各地点内フィット p | 0.013 | 0.007 |
| 頭花が食害された割合 | 90.8% | 31.3% |
| `Larinus`の種子食者内構成比 | 44% | 84% |
| 幼虫数／頭花 | 5.4 | 0.26 |
| 最大観察花頭数／母植物 | 33 | 65 |

**数理再計算した集団間係数比 `a_Nikko/a_Kawamata=8.4`**。この2集団で同じ小花数を飽和式へ代入したとき、モデル上の日光での「被害割合の増え方」は川俣より大きい。ただし異なる年・標高・幼虫群集・推定方法の混合効果であり、aの差に独立した信頼区間や相手組成だけの交差実験はない。

`W(F)=S*F*exp(-aF)`（Sは花粉・受精による種子形成確率が一定、花・雄性/資源コストは追加されない）の**仮定した模型**では`F*=1/a`を導ける。ここで元論文の印刷係数からの再計算値は**約15,873／約133,333小花**、比は8.4。原著の有効桁数の高い係数からの表示は約15,783／133,280小花（約35／296頭花）で、印刷係数の丸めが差の理由。これは**植物がその最適値に自然選択で進化した実証ではない**。現場で実際に観察された植物ごとの最大頭花数は33／65であり、「296頭花が自然選択で維持された」と述べるのは誤り。

式からの純粋な**予測値**例（実際の観察割合ではない）は、小花1000で日光6.11%、川俣0.75%。この予測値にCIは無く、元植物レコードを再フィットしたものではない。

公刊原著の直接の肯定結果は、**花ディスプレイの増加でマルハナバチの頭花当たり訪問が一様には増えない一方、種子食者の被害割合は植物のディスプレイとともに増える**こと、かつ実際の種子食者2種の構成比と被害程度が集団・年で異なることである。

## 「相手が違うから利益の符号が反転した」の証拠にしてはいけない

同じ *Cirsium* 種で二つのギルド側の関係を調べた**実証的価値は高い**。だが大切な帰無/交絡が少なくとも4つある。

1. **1998送粉者 vs 1993/1994種子食者は同じ植物・同じ頭花ではない。** 1998の「一定な訪花／頭花」を2000の種子損失に直接足し引きして「選択勾配」と呼ばない。柱頭への実際の花粉沈着・花粉輸出も計測されていない。
2. **二地点で頭花の向き・真の刺長・粘着分泌物を操作していない。** 視覚的なディスプレイ増加からの昆虫集積と、頭花の構造による物理的接触・入口遮断を区別する必要がある。
3. **川俣の被害量は日光の52種子/幼虫を転用したモデル推定**。モデルaの8.4倍は、この可搬性の仮定と年/site構成に依存する。川俣での直接計数と同じではない。
4. **昆虫相の変化は種組成の交差実験ではない。** 日光の`Larinus`44%に対し川俣84%だったが、温度・標高・密度・開花期・年・母植物資源量の違いと交絡する。「Deliaが粘着性に弱いから日光で食害が強い」は今回どの観察からも支持されない。

強い自然史があるのは、実際の相互作用相手候補 `Bombus diversus`, `Larinus meleagris`, `Delia platula` を既に特定できている点。だが**花頭の向き×刺で同じ昆虫が阻害されるか**は未測定である。

## aza3の主研究をどう改善するか

この二地点比較を**「頭花の構造の適応」ではなく、花頭ディスプレイという別経路の陽性対照**に指定する。少数の実測でQ2を識別できる条件は：

- `C. purpuratum` など実際の主要昆虫を記録した系で、頭花数・小花数・同時開花密度を、向き・真の刺・総苞形状とは**別の説明変数**として測る。大型花頭が種子食者を引き寄せることと、接触後に刺が入口を塞ぐことは別。
- **事前登録した頭花と有効録画区間が分母**。正当なマルハナバチ訪問の花粉沈着、`Larinus`と`Delia`それぞれの頭花外面接触→本物の産卵→損傷後の幼虫位置/痩果を別々に計上し、失敗接触と最終迂回も残す。
- **同一集団・同一開花段階・同じ相手曝露**で頭花向き/総苞形態の違いを比較する。交差処理は植物や頭花への損傷・香りの変化をshamで監査し、保全制限と現場許可が独立に満たされた後に限る。
- 植物の繁殖利得は頭花当たりの充実痩果という最終尺度へ戻す。「昆虫来訪」「種子食害成立」「損失率」「最終成熟種子」を一つの割合へ縮約しない。
- **同じ昆虫相でも頭花形態の効果が無い**とき、花香/ディスプレイと昆虫タイミングで説明できるなら、物理障壁仮説を明瞭に棄却する。多機能構造だから衝突しているとはしない。

### 3問への接続と上限

- **Q1（turnover+chun+EAzami）**：この2地点の系内相違は形態状態の**系統的な記憶**ではない。単一種内部の生態的露出/価値変動であり、別系統での保存や遺伝的再利用と混同しない。
- **Q2（bita+sch+balance+slk）**：**植物が同じでも相互作用相手と環境によって攻撃成立率/被害程度が大きく違う**という重要な実際の背景結果。ただし機能的利益が相手種によって符号反転することも、進化的な最適化も未実証。
- **Q3（anto+egwe+izu-core+aza3）**：DNA・花色経路の再発現については、この研究から情報が増えない。
