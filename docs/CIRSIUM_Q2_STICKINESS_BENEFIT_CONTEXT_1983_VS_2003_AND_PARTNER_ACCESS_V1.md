# Q2 実測文献から判明した重要な結論：アザミ頭花の粘着性による防御利益は一様ではない

2026-10-19 | `aza3` PR #50 | `bita + sch + balance + slk` の実証上の重要な反例。**元研究の再解析ではなく、公刊実験の観察方向を厳密に比較した evidence synthesis**。

## 実証上の発見（既知の1983年の実験をEAzamiの相互作用seedに追加した）

EAzami の凍結済み相互作用マップ `data/evidence/cirsium_interaction_evidence_seed_v1.csv` は15行（独立論文13本）で、*C. discolor* のThomas 2003（粘着物質を中和しても種子食・種子生産への明瞭な影響なし）を含むが、**より以前のWillson, Anderson & Thomas (1983)による2種の直接操作実験を含まなかった**。これらを単に「粘着性の防御機能は否定された」と統合することは不適切である。

## これが最も大事な生態学的区別

**すでに支持される結果**

1. 頭花の**同じ種類の外部粘着構造**を無効化したときに、種子食害の増加が検出される *C. discolor* 条件（1980）がある。
2. 同属 *C. flodmani* および別観測期間の *C. discolor* では、**同じ機能の効果が検出されなかった**。
3. *C. discolor* では、昆虫群ごとに粘着部位を通る／避ける／妨げられるという**物理接触の違い**が観察されている。

**まだ支持されていない解釈**

- 粘着性への選択圧が正から負へ**符号反転した**（陽性 vs 無検出はそうではない）。
- 同一形態で異なる相互作用相手を実験的に入れ替えたところ、植物適応度への利得が逆転した（相手の組成は未独立操作）。
- 1983年の結果が種子食者の種組成、局所密度、フェノロジー、総苞の形状のどれに依存したか。
- 保護対象の頭花粘着性が、総苞の**本物のトゲ**、頭花の向き、花色と遺伝的に連動する。
- *C. lineare*（JPN15）や *C. dipsacolepis*（JPN06）で1983年のC. discolorの効果がそのまま生じる。

今回得られた自然なQ2は、**「同じ頭花の外部の一つの構造が、相手群集と実際の侵入口により、植物の受ける利益を変えるか」**である。粘着部位を避ける正当な送粉者、粘着部位を迂回する種子食者、妨げられる種子食者、アリや捕食性節足動物を同じ「花に来た昆虫」として扱わないことが最優先。

## aza3のEAzami系統に具体的に落とす

既存[EAzamiのモジュール機能ブリッジv2](https://github.com/zuizui0223/EAzami/blob/c9870e91604ed1514344ddc8f765eae5237dbf27/data/evidence/japan38_module_function_bridge_summary_v2.json)には、JPN06 *C. dipsacolepis* は**非粘着**、姉妹候補JPN15 *C. lineare* は**粘着**、両者の核樹姉妹支持は100/100、と固定されている。JPN36 *C. sieboldii* は非粘着・圧着気味の総苞片。

**より少ない実験で利益の文脈を特定する手順：**

1. **観察に先行した頭花登録**：JPN15 と JPN06 の現場で、実際の総苞分泌・本物のトゲ長・花頭の重力方向・頭花順位・フェノロジー・性、環境と安全な撮影視野を**同じ方法で**測る。比較はまず種間差の記述であり、形態と他の遺伝的差が交絡するので因果ではない。サイトでの存在・アクセス・開花実績はまだ未確認。
2. **昆虫が来る順序を実測**：到来 → 粘着部位との実接触か迂回か → 侵入阻害または別入口への切替 → 花粉沈着の独立証拠／種子食者の真の産卵 → 成熟した充実痩果。昆虫目だけの自動分類とGloBIの共起は相手の**有効な機能役割**を同定できない。可視カメラが昆虫と粘着面の微小接触を解像できなければ `NA` にする。
3. **許可・実行可能性ゲートを通った場合のみ**、粘着なJPN15で中和または粘着性を無効化する処理 vs 傷つけないshamを植物単位で割付。処理が香り・色・水分・総苞表皮を変えないことを予備検証。種子食者群集の実際の攻撃経路別に評価し、**捕食性の節足動物/寄生蜂が実際に種子食を抑制・増幅するか**を別に測る。相手群集が異なる複数地点の観察は地理・環境による交絡を残すため、因果的な相互作用の推定には独立した許可済み交差操作が望ましい。
4. 実際に処理した頭花では、*個々の接触失敗*とは別に**全処理植物の最終充実痩果数**を記録。寄生蜂の羽化成功個体だけ、産卵成功頭花だけを抽出して全体効果を推定しない。持ち帰り・組織採取・トゲ切除は既存の観察許可だけでは行わない。
5. **結果は三方向とも有意義**：粘着処理の種子食害防御が再現／ギルドが迂回し真の機械的機能が弱い／送粉阻害や捕食者依存の費用で利益が相殺される。機能が相手で正から負に変わるかを言うには、同じ `z` の独立操作×相手条件で `W(z,P)` が必要。

### SCH/BITA/BALANCE/SLKの検定を混同しない

- **BITA**：実際の生物相手が共有構造の別ポータルを使い、成功率を変える。形態への物理接触観測から反証可能。
- **SCH**：同じ形態軸`z`への送粉機能と種子防御機能の**異なる適応度勾配の符号**が反対か。両機能の存在だけなら「衝突」と認定しない。
- **BALANCE**：同じ個体の形態軸の中間域に妥協最適値が実在するか、あるいはギルド条件で動くか。まず実在する成功率と最終`W`を測る。
- **SLK**：最適値の衝突 `L>0`、形態モジュール分割で回収できる`R`、形成の費用`K`、構築可能性、進化的固定を**別のゲート**とする。1983/2003の既存比較で`Phi=R-K>0`と計算しない。

## 自動監査結果と停止条件

新規[公刊実験の証拠台帳](../data/evidence/cirsium_stickiness_real_primary_context_evidence_v1.csv)は4個の **study×species／観測成分**を含むが、**独立の介入論文は2本、介入種×論文の比較は3つ**であり、独立実験数を4とも3とも称しない。2007年は相手別接触の観察研究で、介入処理ではない。1983＋2003の一方有意・一方非有意という「有意性の差」から統計的な相互作用の検定が成り立ったとは言わない。

スクリプト `analysis/audit_cirsium_Q2_stickiness_partner_contact_real_sources_v1.py` は EAzami凍結済み15ソースを毎回読み、1983年の漏れと2003年のNULLを直接照合し、源で認めていない効果量/p/標準誤差の捏造、真の刺と粘着性の同一視、`C. flodmani` nullの棄却、2007観察結果の因果実験昇格を拒否する。**新しい同属野外効果量をフィットしたものではない**。

**最小の次の根拠**：許可された現場または公開動画で、JPN15の粘着総苞と正当送粉者・真の種子食者がどの程度実際に接触するかを、未到来を含む全撮影分母で確認する。もし粘着面に種子食者が物理的に全く接触しなければ、「粘着トラップがその種子食者を妨げる」機構はその集団で反証候補になる。現時点では JPN15/JPN06 の同時刻実測ギルド/適応度/先祖部品遺伝状態は**0新規測定**、Q2 の相手依存の**因果利益は未同定**。
