# Chapter 3 sample-sector execution v7

This document is the operational bridge between the exact species-level hole ledger and later exact-locality field planning.

## Governing rule

The Japan-wide nuclear tree is filled against the current NMNS/Moreyra species-level screen. Range sectors are frozen before exact sites. Exact localities and coordinates remain closed until current occurrence, conservation status, access and tissue permissions are verified.

For two-new-sample taxa, sample A and B should represent different verified wild populations or range sectors whenever the NMNS distribution supports that design. If a taxon is restricted to one locality, island, mountain or prefecture, do not invent a second range: use a second independent wild population when available, otherwise a spatially separated independent plant and flag the limitation.

- Hamaazami block: `C. brevicaule` uses Amami Oshima + Okinawa Honto; `C. irimtiense` uses Miyako + Ishigaki; these are the same individuals/populations used by M01.
- Norikura-series block: `C. fauriei` uses Central Alps + southern Northern Alps; `C. otayae` uses Myoko + Hakusan systems.
- Yamaazami block: `C. albrechtii` uses Kushiro-side + Hakodate-side Hokkaido populations; limestone taxa use separate Okayama/Hiroshima limestone populations where documented.

## P6 complement rule

P6 is different: the public tree already has one usable Moreyra representative. Therefore the new own sample must not be chosen blindly from the same population. Resolve the public accession locality first, then choose a verified wild population from the most geographically complementary NMNS-documented range sector. `C. dipsacolepis` and `C. lineare` are exceptions operationally because their own representative is drawn directly from the focal RAD banks.
