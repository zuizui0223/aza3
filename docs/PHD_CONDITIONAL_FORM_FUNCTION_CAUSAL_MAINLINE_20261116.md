# 博士研究の検証仕様 v2：形態から機能への写像は進化史と環境で変わるか（2026-11-16）

**状態：研究仮説と事前分析仕様。新規RAD-seq・自然の頭花機能データ・適応の正の結果は取得していない。** 既存[博士主線](PHD_PHYLOGENY_BM_OU_NICHE_NATURAL_CONTRASTS_20261115.md)・[属外文献比較](PHD_CROSS_CLADE_FUNCTIONAL_LANDSCAPES_AND_NICHE_20261115.md)・[自然対照台帳](../data/planning/cirsium_phd_natural_contrast_panel_20261115.csv)を継続し、対象種や主要形質を増やさない。

## 1. 中心の問いと4つの区別
**異なる系統・集団に由来する頭花は、重力基準の向き O と総苞の真正な棘／開出 B の異なる組合せによって、同じ有効送粉・食害回避を実現できるか。その形態→機能の写像は、降雨環境 E と観測された昆虫ギルド G によって変わるか？**

混同しない4つの現象：
- **同じ形態、同じ機能**：形態と機能の単なる保存。many-to-oneの証拠にならない。
- **異なる形態、各機能が実質的に同等**：機能的等価性候補。形態の違いが測定誤差を超え、花粉沈着・実際の産卵／損傷・成熟充実痩果という**多成分指標のすべて**が事前の意味ある等価性範囲に入る必要。
- **異なる形態、送粉／食害経路は違うが最終充実痩果は同等**：純量の一致・経路補償候補。**機能が同じ**とは呼ばないし、機構的な補償の因果はまだ不明。
- **同じ形態、場所や実在ギルドにより効果が変わる**：環境依存的機能景観。局所的な生殖利益の変化を、祖先の適応史と同一視しない。

2025年の [Kay & Anderson, Annals of Botany](https://doi.org/10.1093/aob/mcaf096) は複数の訪花者を統合した花の適応景観という一般概念を明示し、2026年 [New Phytologist genomic review](https://doi.org/10.1111/nph.71605) は組合せ形質の適応と遺伝的な境界を扱う。2026年 [Annals of Botany covariance study](https://doi.org/10.1093/aob/mcag186) は形質平均だけでなく共分散構造の収斂を検討。**これらの一般理論そのものは本博士の新発見ではない。**

## 2. 形態進化と機能実験を別の推定対象にする
**歴史 H（第1章）**：公刊350核座位の背景系統と、条件を満たした焦点種のRAD集団史で、開花期O・総苞B姿勢・真正のトゲ・粘着の祖先状態分布と反復変化、共変化を推定。真正のトゲの祖先史は未取得測定を新設するまで不可。若い多型系統では単一tip/単一状態への圧縮を避ける。

**比較進化 N（第2章）**：BMを帰無に、誤差・適切な枝長・樹アンサンブル・独立変化の数を調べ、OUは識別力がある場合だけ。系統のOU推定最適値 theta と、実際の繁殖成果を最大にする現在の O×B は**異なる推定対象**。気候ニッチだけでなく現場の実現昆虫相を扱うが、分布やGloBIから地点の昆虫相を創作しない。

**機能 F（第3章）**：同じ植物の印付き頭花を蕾→開花→結実で観察し、校正済み角度と総苞の真の棘／隙間、性型・頭花数/サイズ・花柄支持・天候・花期を測る。イベント記録は来訪ゼロを含む有効撮影時間を分母として持ち、同じ母植物の花粉付着・真の産卵／損傷・成熟充実痩果を分けて報告する。頭花数を独立した母植物のサンプル数に置き換えない。

## 3. 因果設計（主たる操作は増やさない）
主介入は、非損傷・許可済みの**向き変更と偽操作のランダム割当**。向きの介入は O の因果効果を与えるが、自然の B を変えていないので B そのものの因果効果は与えない。

### 主要推定対象
`tau_O(B, E, G)` = 同じ B／調査条件の下で、ランダムな向き処理が同一種花粉沈着（および事後の成熟痩果）をどれだけ変えるか。Bは**操作前の効果修飾因子**として扱い、Bを意図的に変えたと断定しない。

介入群ごとの花粉・損傷・痩果を条件別に報告。昆虫が観察された結果を単純に「原因変数」として一次全効果のモデルに投入して処理経路を消さない。花期×Oの変化や同株内頭花間の干渉が強ければランダム化単位を**母植物**へ変更し、記録する。

## 4. 実証しうる新規性は何か
既知（オリジナリティの対象にしない）：多機能な苞葉、保護と送粉のトレードオフ、花の向きの雨保護、多形質のOU進化、trait covariance の収斂、遺伝的なモジュール性という一般概念。

実証できた場合のみ新しく主張する：
1. 頭花Oと真正Bの系統上の独立／条件付き変化を、祖先と集団構造を考慮して同定。
2. 同じ開花期・性型で実在する自然形態の組合せが、**異なる形態のまま同等の複数機能**を実現するか、または「同じ最終種子数でも経路は異なる」かを判別。
3. ランダム向き操作の効果が実際のB・降雨・昆虫ギルドに依存し、独立集団で再現／予測できるか。
4. 第1章の歴史と現在の機能を**対応させる**。2群の野外機能差だけで選択の歴史的方向や遺伝的モジュール再利用は証明しない。

## 5. 自然対照の優先順位・予測
**本研究の一次対照** N01 *C. kiotoense* の種内多型。試験前に同地点・同花期・同性型で O と B が独立変異するか、**組合せ全域の重なり（positivity）**を確認。なければ O×B 共同機能は推定不可。観察データのみでのB機能は因果と呼ばない。

**独立する発育対照** N03 *C. sieboldii* の開花直立型／点頭型。花後の直立を開花直立型と混同しない。**N02 カガノアザミとの共生**は同所・同時期・同じ昆虫相が現地で確認された場合のみ予測検証候補。N05 モリアザミ–ヤナギアザミは祖先に近い総苞粘着性対照で、真正の刺効果へ流用しない。

## 6. 機能的等価性を証明するための統計的な停止条件
- 等価性の意味ある幅は結果を見ずに**機能ごとに**登録する（同一種花粉の相対変化、種子被害確率の絶対差、成熟充実痩果の相対差は同じ単位ではない）。
- 各必要機能の**適切な母植物・集団階層の90%信頼区間**が、事前に定めた上下の等価性範囲内に**完全に収まる**ことを等価性の最低条件にする。TOST等の原理を参照：[equivalence primer](https://doi.org/10.1249/mss.0000000000001481)。非有意だけでは等価と言わない。
- 最終痩果のみ等価、花粉または食害が明確に違うなら `SAME_NET_SEED_WITH_DIFFERENT_COMPONENTS`。これは機能の等価性ではない。
- 主仮説の通過が観察計画だけにとどまる場合は「条件付き関連」。追加の保全・許可・安全基準を満たさない真正のトゲ切除は実行しない。
- 実験とマクロ進化の間の表現型–機能写像を世代・系統に拡張するには、複数独立の遷移と遺伝的変異が必要である。

## 7. 合成精度診断（生物データではない）
[精度シナリオJSON](../data/planning/phd_form_function_precision_scenarios_20261116.json) と[再計算スクリプト](../analysis/phd_form_function_equivalence_gate_v1.py)。
母植物差のSDを**仮に**0.4または0.7（標準化された仮想尺度）と置き、独立母植物数24・60・120を仮定した場合の**90%正規近似CIの半幅**：
- SD=0.4 では **0.134 / 0.085 / 0.060**
- SD=0.7 では **0.235 / 0.149 / 0.105**
あくまで精度目安。±0.1という架空の等価幅に収まり得るかを見るものであり、実際のアザミにおける検出力、予想変動、推奨個体数、結果を示さない。場所/年/観察機会の分散も加算していない。**GROWの50–60母植物が機能的等価性に足りるという保証はない。** 独立パイロットで実際の階層分散と実現可能な差を推定してから本実験数を決める。
