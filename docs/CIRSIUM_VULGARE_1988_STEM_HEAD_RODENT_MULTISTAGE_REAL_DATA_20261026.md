# aza3 Q2｜同じアザミでも、何に食べられるか・いつ食べられるかで繁殖制限の構造が変わる

**2026年10月26日：*Cirsium vulgare* の原著表を再計算し、茎・頭花・散布後の3段階で敵と分母を厳密に分離した。**

出典：Klinkhamer, P. G. L., de Jong, T. J. & van der Meijden, E. (1988), *Journal of Ecology* 76:403–414, [DOI 10.2307/2260602](https://doi.org/10.2307/2260602)。[著者が公開した原論文全文とTable 1/2](https://www.researchgate.net/publication/271759934_Production_Dispersal_and_Predation_of_Seeds_in_the_Biennial_Cirsium_Vulgare)を照合。オランダのMeijendel海岸砂丘の研究。**原著の個体別・頭花別の生データを新しく取得したわけではない**。原論文の表・方法・元著者による数値を独立JavaScriptとPythonで再計算したものである。

前の [PR #93の1983/2003年の粘着性総苞研究](CIRSIUM_STICKY_BRACT_REGIME_DEPENDENT_FUNCTION_Q2_20261024.md) のPDF本文配信は403で、当該2論文の新たなn・p値の再構成はできなかった。今回の実際の新しい植物データ系は**1988年 *C. vulgare* 研究**であり、異なる著者・種・地域の資料を同じ植物に接ぎ木していない。

## 新しい実測による中心的な結論

**同じ種・同じ研究地でも、茎の害を受ける植物の頻度は大幅に低下した一方、花頭内の種子食害が観察される頭花の頻度は上昇した。** しかも1984年の植物単位の種子生産は大幅に増加しており、「頭花が食害された割合」だけからその年の植物繁殖制限は説明できない。

| 同じ研究地の元データ | 1982年 | 1984年 |
|---|---:|---:|
| 茎の食害を調べた無作為選抜の開花植物 | **117株** | **67株** |
| 茎に食害痕のあった植物 | **98%** | **24%** |
| 植物1株あたりの平均種子数（全調査植物） | 50±7 SE | 1,470±87 SE |
| その年の無傷茎を持つ植物の平均種子数 | 246±36 SE（**52株、うち50株は追加の非無作為選抜**） | 1,713±245 SE（51株） |
| 原著が比較から計算した茎の食害による種子生産減少 | 約80% | 約15% |
| 食害痕のあった頭花 | **67/268＝25.0%** | **49/97≒50.5%**（原著51%） |
| 食害痕ありの平均種子数／頭花 | **37±2 SE** | **139±12 SE** |
| 食害痕なしの平均種子数／頭花 | 43±2 SE | 208±14 SE |
| 原著推定の頭花内での種子食害損失 | 3% | 17% |

**年による記述的変化：** 茎食害植物の割合 **−74ポイント**、頭花食害痕ありの割合 **＋26ポイント（原著丸め値）**、原著の茎由来種子減少 **−65ポイント**、頭花内での種子食害損失 **＋14ポイント**。異なる実測段階の結果を同じ確率として比較したものではなく、年による敵集団・植生・水分、植物サイズ・種子供給量の変動が混ざっている。

**観察群内での頭花差も異なる：** 1982年は食害痕ありの頭花が食害痕なしより平均 **6粒少ない**（37 vs 43、元研究の標本群ごとの平均）、1984年は **69粒少ない**（139 vs 208）。しかし食害個体が無作為に決まっておらず、比較した頭花のサイズや利用資源が異なる可能性があるため、**この差を「虫を除去したときに戻る種子数」とは呼ばない**。原著の損失率3%／17%と、群間平均種子数の差に基づく約14%／33%は**同じ分母の推定値ではない**ため、いずれも分けて保存した。

### 茎食害の80%を「無作為操作の80%の因果効果」にしない

1982年には、茎の食害がない植物は無作為標本117株のうち**わずか2株**。著者らは無傷茎比較を行うため、**非無作為に50株を追加**し、無傷標本52株の平均種子数を計算した。したがって `1−50/246≒79.7%` は**無作為対照試験で得た処置効果ではない**。1984年の `1−1470/1713≒14.2%` も観測植物の比較である。茎食害の種類にはウサギ、双翅目の茎食虫 *Cheilosia grossa*、鱗翅目の *Epiblema scutulana* などが含まれ、頭花に侵入する幼虫と同じ「一種類の昆虫」としてまとめられない。

### 頭花の食害痕があっても、植物全体の種子が少ない年とは限らない

種子数は1982年の植物平均50粒から1984年の1,470粒へ増えているが、**同時に頭花食害痕の頻度は25%→約51%へ増加**した。原著が議論する干ばつ・7月の降水、茎を破壊する植食者の変動、花頭数や植物発達条件を無視すると、頭花側の「敵の増加」をそのまま個体の繁殖成果悪化の説明としてしまう。これは食害の悪影響がないという意味ではなく、**異なる発生段階の効果を統合する際に背景条件を保持しなければならない**ことの実証である。

## 散布された後の本物の囲い込み実験では、さらに別の敵が働く

原著のTable 2は**1981年9月〜1982年2月の独立した散布後種子実験**であり、1984年の植物から採った頭花と同じ種子を追跡した実験ではない。著者は植生を含む容器に種子を播き、次の3処理を設けた。

- **小さい網目のcage（0.6 cm）：** 鳥と小型ネズミ類の侵入を妨げ、小型昆虫は通過可能。
- **大きなnet（2 cm）：** 鳥を妨げ、ネズミ類・小型昆虫は通過可能。
- **open：** 外敵のアクセスを妨げない。

スクラブと草本植生という2つの環境、**5観測日×2環境＝10個の表セル組**で公開された種子の損失割合を再計算した。

| 元の公開Table 2処理 | 10個の環境×日の損失割合の等重み平均 |
|---|---:|
| **0.6 cm cage** | **6.2%** |
| **2 cm net** | **65.4%** |
| **open** | **63.5%** |

同じ環境・日における **open−cage の差は平均＋57.3ポイント**、**net−cage は＋59.2ポイント**。**10/10の組で小さなcageより、openもnetも損失割合が高い。** openとnetの差は平均わずか−1.9ポイント（net−openは＋1.9）、原著も両者に有意差を検出していない。原著の独立実験単位に基づく検定では、cageはnet/openと各回有意差（原著のWilcoxon対応比較p<0.05）と報告された。**10個の公開集計セルを10の独立した処理反復とみなして新しいp値を作ってはいない。**

重要なのは、これは真の総苞刺防御に関する操作ではなく、**種子が花頭から出た後の鳥・ネズミ類へのアクセス制限**であること。小さい網目で大きく損失が減ることと鳥だけの網で減らないことは、この砂丘の種子散布後に**小型ネズミ類が重要な種子捕食者**であるという著者の解釈に整合する。同じ原著の95地域実験では週平均約39%、別の9区画の種子播種追跡では約3週で約60%の種子が失われた。これらも**異なる原著実験の集計**で、1982／1984の同一頭花IDではない。

## Q2の実証に対する強い結論と残る対立仮説

**実測支持：** *Cirsium vulgare* で、種子の運命を決める障害は少なくとも「開花茎の破壊・頭花内幼虫の食害・散布後ネズミ類の捕食」という異なる入口・時間の作用に分かれ、それぞれの重要度の観測値は年や環境により異なる。ある年の**頭花内食害痕の数や割合だけを、その年の植物適応度または次世代の成功率とみなすことは誤り**。

**まだ検証していないこと：** 頭花の真の角度・総苞間隙・トゲ・粘着が上記のどの侵入を防ぎ、どの送粉者の柱頭接触を助けるか。原著にはその構造操作・送粉成功データ・同じ母植物のすべての種子段階連結IDがないため、「総苞の遺伝的LEGOが環境間で組み替わる」「形態的防御の選択が反転する」「再現可能な遺伝的祖先経路が残る」とは言わない。

**ここからの論文上の問いはより精密になる。** Q2の真の適応価値は、送粉者と敵の頭花への**接近成功率だけ**でなく、その時点までたどり着いた胚珠・種子の数、そして散布後に次世代へ残る機会に条件付けられる。今後の同一頭花の実験では、既存 [PR #86の連続録画・昆虫接近分母](AZA3_Q2_REAL_HEAD_FUNCTIONAL_ACCESS_MAINLINE_20261023.md)、実測した頭花モジュール、成熟痩果数、母植物の位置別種子供給を連結し、個体の後期段階（散布後生存）を別サンプルで明示的に推定する必要がある。

**科学的安全弁：** 原著の茎生産減少率80%・15%と頭花内種子食害率3%・17%は**分母が違う**。それらを足し算・掛け算し、1982／1984の一植物の「最終適応度」を架空計算してはいけない。
