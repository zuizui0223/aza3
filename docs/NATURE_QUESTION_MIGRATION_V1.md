# aza3 Nature-question migration note v1

Date: 2026-10-06

## Current single question

Must an integrated complex organ evolve as an integrated unit?

The Nature-scale programme now treats this as the sole primary question.

The strongest alternatives are:
- whole-organ inherited integration (F);
- inherited phenotypic modules (M);
- reconfigurable inheritance that can break the phenotypic-module partition (R).

## Status of the older reuse hypothesis

Earlier aza3 planning asked whether rapid capitulum diversification was fueled by reuse, sorting, introgression or regulatory redeployment of pre-existing genomic variation.

That remains biologically interesting, but it is no longer the primary Nature claim.

It is now a mechanistic subquestion conditional on the inheritance-unit result.

If R is supported, the next mechanistic question is: where did the reconfigurable genomic components come from?

Possible answers remain:
- ancestral standing variation;
- introgressive reuse;
- recurrent de novo mutation;
- regulatory/homeolog reuse;
- mixtures of these.

If F or M is supported, source-history analyses can still be performed, but they do not rescue the reconfigurable-integration claim.

## Why the hierarchy changed

Different components reuse old variants combines two logically distinct questions:

1. what is the unit of inheritance/evolution?
2. what is the historical source of the variants carried by that unit?

The first can change a general assumption about complex-organ evolution.

The second explains the mechanism in this radiation.

For a one-question Nature paper, inheritance unit is therefore upstream.

## Document interpretation rule

Legacy files that describe reuse of pre-existing variation as the Nature-scale headline are retained as historical planning records.

They must be read under this hierarchy:

inheritance-unit test (F/M/R) -> component source history -> function/fitness

not:

reuse must be true -> search for supporting component histories.
