# GROW博士B③｜琉球アザミの新地域進出と「潜在的な祖先形質形成能力」：RAD-seqで何が識別できるか

**2026-10-27／aza3 Cirsium実証の計画・原著と公開資源の監査。** 主線：D1 A①（核系統・祖先状態・反復進化）→D2–D3 A②（送粉・食害・気象による自然選択・適応）／D3 B③（潜在的な形成能力の保持；実際の再発現・世代間維持は発展）。新たなRAD配列取得、試料受領、採集・操作実験の完了は**なし**。

## 研究の正確な問い
「植物が分布拡大・進出に伴って創始者から運び込んだ祖先的な遺伝・発生資源は、その後に**見える頭花形質が一時的に失われても保持**され、新しい地域で**実際に再発現・遺伝・維持**されるか？」

ここでいう「進化的記憶」＝**検証可能な、祖先由来の機能的ゲノム／発生資源の保持**。形態が似ているという印象・系統的信号・現在のDNA配列の存在だけでは機能的保持を認定しない。

**最優先の事実訂正**：現生 *Cirsium brevicaule*（中央琉球・白）→現生 *Cirsium irumtiense*（南琉球・青紫）という直線的な祖先子孫関係を仮定しない。両者は共通祖先から分かれた系統であり、**白→紫という祖先形質の再活性化もまだ未実証**。また単に「南のほうが新しい環境」という地理的解釈を、分散方向や創始順序と同一視しない。

## 検証すべき競合する形質史

| 仮説・必要な進化史 | 核RAD/集団データから言えること | 実際の再利用・適応を主張するために追加で必要な独立証拠 |
|---|---|---|
| **H-retain（着色祖先→南で保持／中央で白花化）** | 2系の核祖先・分離・分布史のモデルを比較。外群を含めた祖先花色の確率を推定。 | 南側の着色経路が**消えずに継承**されたかを花色素化学・花器官RNA・関連ハプロタイプで検証。**再発現説とは異なる**。 |
| **H-reactivate（低色素／白祖先→南で同じ祖先経路を再起動）** | 祖先低色素説が推定可能か、分布史と形質変化順序をモデル比較。RADは**この履歴を候補とするまで**。 | 実際の**表現抑制が祖先にあった**という独立の祖先史、機能資源の継承、花での再発現と分子経路の相同性、代替的な新規変異・移入の除外。時間が許せば共通園・交配・誘導。 |
| **H-sort（祖先集団で両型／変異が既存→創始で選別）** | SNPによる集団構造・遺伝的多様性、創始者モデル・混合の可能性。 | 同じ花色関連の**古い機能的ハプロタイプ**が複数祖先系統に維持されていること（密なゲノムと変異史）。「白→紫」の新たな再進化でなく、祖先多型の仕分けかもしれない。 |
| **H-introgress（他系統から着色関連領域が移入）** | RADの多座位信号で混合や遺伝子流動の候補を検出できる場合がある。**無信号でも古い/局所的遺伝子流動を排除できない**。 | 高密度ゲノムの局所祖先・形質関連領域の系譜・変異の伝播と花の発現。 |
| **H-de-novo / recruitment（新しい変異や異なる調節因子の動員）** | RAD単独では祖先資源が再起動したのか、別の新変異が色を生んだのか判別できない。 | 発色関連の原因領域、花の発現・代謝、機能試験。例：*Petunia exserta*の別のMYBパラログ利用は一般的な参考でありアザミの事実ではない。 |
| **H-plasticity（環境・成熟段階に依存）** | 同じ個体の頭花状態が環境と共変してもRADだけでは遺伝的変化を検証できない。 | 共通環境で生育し、同発育段階で花色・色素・発現が再現するか。後代/親子での分離や母性環境の影響を分離。 |

**形質の再出現**は、①元々色が残っていた、②祖先の抑制されていた経路が再活性化した、③古い変異の選別、④新変異、⑤移入/新系統の侵入、⑥可塑性、のいずれでも生じ得る。**「再起動」と言ってよいのは②を明確に支持した場合**に限る。

## 2026年原著の独立した検証
**Chang et al. (2026) BMC Plant Biology, DOI 10.1186/s12870-026-08097-6**
- 合計37アクセッション（Cirsiumと外群）、約3000 single-copy核遺伝子の系統推定、*brevicaule / irumtiense*は宮古海峡を挟む互いに区別される琉球系統。
- 2系の分岐約 **0.93 Ma（95% HPD 0.71–1.33 Ma）**。**色素化の消失／再獲得の時点・移住方向ではない**。
- *brevicaule*の花冠白・2C核DNA量約1.93±0.20pg、*irumtiense*の花冠青紫・2C約0.69±0.08pg。ただし核DNA量差から正確な倍数性を勝手に断定しない。
- 原著Methodsで新規RNAは**生葉**をRNAlaterで保存し抽出。SRA公開データと同一個体の花器官発現・アントシアニン経路の酵素活性ではない。
- 原著結論には別の台湾var. takaoenseについて「anthocyanin expression / pollinator preference」の表現があるが、少なくともMethodsで新規RNAは**葉**と明示されており、花の因果実験として利用する際は独立に元の具体的な花器官/訪花実験表を確認する。琉球2系での花色経路再起動の証拠と混同しない。
- 種境界は分類体系によって相違し得るため採用分類名・元標本名・系統を同時記録する。

原著：https://link.springer.com/article/10.1186/s12870-026-08097-6 （2026-02-05）

## RAD-seqの「識別力」を厳密に評価する表

| データのレベル | やること | 認める主張／停止条件 |
|---|---|---|
| **Tier 1a：多集団SNP** | 4–5島集団/系統（許される範囲）を反復、各集団の構造・FST・遺伝的多様性・核混合・分化の信頼区間を得る。 | 「集団間の核祖先と構造」。**中立的遺伝的近縁性は花色形成経路の保持証拠ではない**。 |
| **Tier 1b：分布史シナリオ** | 中央→南、南→中央、共通祖先からの別方向進出、複数進出、遺伝子流動など複数モデルを、公開核参照・外群と整合させる。 | SNP多型と集団サイズ履歴、祖先地理に区別可能な情報があれば、一部モデルの相対適合を比較。ただし二地点の現生地理から方向を確定しない。 |
| **Tier 1c：個体別花色・他モジュールとの結合** | SNP取得**同一個体**の校正色、UV、色素、重力基準頭花角度、総苞片の開度/トゲ/粘着、倍数性、画像、花期を連結。 | 個体・集団の**可視形態の遺伝的背景との対応**。固定した白/青紫が各系統で完全に分かれると、形態と系統が交絡するため「色の原因座位」はマッピングできない。 |
| **Tier 2：花色関連の機構判定** | 色多型集団（*C. sieboldii*、*C. japonicum var. takaoense*は調査候補）、高密度リシーケンス/ターゲット座位、局所ハプロタイプ・ゲノム構造、花器官RNA・色素化学、共通園。 | 候補原因領域の再利用/異起源、抑制された経路の機能的保持、導入変異かどうかを条件付きで判定。多型がなければ候補系切替え。 |
| **Tier 3：再発現／適応・遺伝** | 花器官で可視の変化が誘導され、同じ祖先経路が実際に働く証拠と、花色が送粉/種子食・充実痩果に作用するかを分離測定。次世代には共通環境・適格な交配/親子情報。 | 「再発現・再利用」を認める条件。多年生でD3内に世代間維持まで到達しなければ、**PERSISTENCE_UNPROVEN**。 |

**大きな技術リスク：** 2系の2C核DNA量は著しく異なる。RAD断片の回収率、制限酵素部位消失、paralog、倍数性・コピー数、サンプリング欠測がSNP分化の過大推定や偽の座位欠失を生み得る。**RADでアンプリコンが回収されなかったことを色素遺伝子が失われた証拠にしてはならない。** 実際の保存試料と野外の同一DNA/小花を紐づける。

## 3年間での実装：GROW/aza3に過度の作業を積まない
- **D1/A①**：伊藤元己教授から提供予定試料の分類・標本ID/使用権・DNA QC、公開350座位核系統とChang2026核史を参照、重点的なRADの集団間関係、分化・混合、適格なら年代/分布進出の競合モデルと祖先形質の不確実性。琉球の2系の**直接祖先関係は前提にしない**。既定Phase-Aの*brevicaule*75＋*irumtiense*75は対象とする**将来目標**（計150、4–5島集団/系統を想定）であり、採集済み・許可済みでない。DNA/花器官を同じ植物で採取できる場合は後続試料を保存開始。
- **D2/A②**：第一の主研究は向き・総苞姿勢・真正トゲ・粘着・花色・ディスプレイの送粉/食害/雨への機能。形態別の充実痩果と自然表現型選択勾配、許可後の限定的非破壊処理を優先。白紫の地域差は昆虫相との比較候補だが、白/紫が集団・系統で完全交絡なら視覚選好と遺伝的適応を混同しない。
- **D3/B③限定**：琉球比較から**白化の祖先史や機構を識別できるか**を評価し、最良の一つの多型系/対照で小花色素、花器官の調節発現、ターゲット遺伝子配列、核祖先/混合を照合する。確認できるのが保持のみなら「潜在的形成能力の保持」まで。再発現・再獲得の年代と分子経路が不可なら**MECHANISM_NOT_IDENTIFIABLE**として報告。
- **将来**：誘導の機能確認、遺伝的伝達、局所適応の交差試験、独立放散系の再発現一般化。B③未完成でA①/A②研究を犠牲にしない。

## 分子実験が成功/不成功でも研究成果になる判定
- **形態が似るが原因経路が異なる** ⇒ 繰り返しの新規構築/遺伝的冗長性という代替進化機構の候補。原本の密度不足は未識別。
- **白花系統でも祖先色素のコード領域・他器官での使用が残る** ⇒ 祖先の構築資源の一部保持。**花器官再発現可能とは限らない**。
- **南系統と白系統で同じ色素関連ハプロタイプが古くから保持・分離** ⇒ 祖先多型の保有/選別候補。「新地域で再び色素合成を起動」したかは花の発現・祖先経路で別途判定。
- **遺伝子流動の候補がある** ⇒ 新規変異でなく移入による獲得も検討。核SNPが全体混合ゼロでも古い局所移入は残る。
- **機能的な共通資源が見つからない** ⇒ 新規経路/消失/測定不足を分ける。RAD未回収だけで遺伝子消失とはしない。
- **色素は誘導されるがF1未開花** ⇒ 個体内の誘導・可塑性の証拠までで、進化的維持/形質の遺伝的再起動の証拠ではない。

## 申請書のB③向け短文（推奨）
「新たな地域に進出したアザミ系統では、見かけ上失われた頭花形質を形成する祖先由来の遺伝・発生資源が保持され、後に再利用される可能性がある。琉球列島の白花シマアザミと着色イリオモテアザミを初期比較系とし、RAD-seqと既刊の核系統樹から分化・遺伝子流動・複数の分布進出史および祖先花色の候補を推定する。ただし現生2系統を直接の祖先・子孫とみなさず、花色の再発現を既知の事実とはしない。代表する多型系で花器官の色素・候補遺伝子発現・高密度ゲノム領域を解析し、祖先資源の保持、後からの移入、独立の新規構築を区別する。再発現や世代を越えた維持の証明は、博士期間に得られる実験条件に応じた発展課題とする。」
