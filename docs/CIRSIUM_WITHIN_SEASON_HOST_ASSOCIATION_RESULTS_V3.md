# 同じ月でも、アザミ種と訪花者の対応は残るか

2026-10-20。aza3 Q2の探索的公開DB解析。前回PR #55の同じ3,243訪花観察IDと回収済み日時を使用し、新しい生物学的観測は追加していない。

## 結論

**Cirsium arvense と C. vulgare の同じ地域・暦月の記録では、同じアザミ種に属する訪花記録どうしの昆虫種一致率が、異なるアザミ種間より高かった。** 各観察者が各アザミを記録した件数を固定した参照モデルにも、平均で2.47パーセントポイントの超過が残った。ただし、同じ観察者・同日の両種記録は15件だけで、その厳しい参照比較は明瞭ではない。頭花構造による選別、昆虫の選好、植物の繁殖利益を実証したとはしない。

## 今回の問いは、前回の問いと違う

前回は「地域間差と種間差のどちらが大きいか」を、同じ2種×同じ2地域の比較で調べた。今回は**各地域・時間層の中の種間の対応**を調べる。地域が違えば一致させる月は7月または8月と違ってよいが、同じ比較層に入る2種の月は必ず同じにする。

主条件は元の2度グリッド、各種×地域×月10件以上、3地域以上に記録がある種ペア。全42種名を対象に機械的に選び、結果の大小では対象を選んでいない。条件に合う比較層があるのは4種ペア、3地域以上を満たすのは **arvense–vulgare の1組、5グリッド・5地域月・191件・86観察者**だけだった。5グリッドを独立した標準化野外実験や5個体群と呼ばない。

**191件は元の3,243件の部分集合であり、前回の3種×共通5地域513件を季節補正した結果ではない。** 推定対象も選ばれる記録も異なるため、前後の差を季節の因果寄与へ換算しない。以前の厳密な年・月合わせで十分な反復がなかった結論も変わらない。

## 指標と実測記録の結果

二つの異なる記録を取り、同じ昆虫種名が記録される確率を計算する。同じアザミ種内の確率を2種で平均し、異なるアザミ種間の確率を引く（U）。同じ記録を自分自身と比較しないため、少数標本から生じる機械的な正の差を避ける。独立標本の母数では二つの訪花者確率分布の二乗差和の半分だが、有限標本推定値は負になり得るのでゼロへ丸めない。

| 主比較の量 | 値 |
|---|---:|
| 同じアザミ種内の昆虫種名一致確率、地域同重み | 11.87% |
| 異なるアザミ種間の一致確率、地域同重み | 7.62% |
| 差 U | **+4.26ポイント** |
| 観察者ごとのアザミ記録件数を固定した参照期待値 | +1.79ポイント |
| 観測値 − 上記の参照期待値 | **+2.47ポイント** |

参照モデルは、同じ地域・月・観察者の中だけで、観察者のアザミ別記録件数を維持して昆虫種名を割り当て直す。期待値は超幾何分布の平均・分散から厳密計算した。両種を記録した観察者ブロックで交換できるのは **58件、12ブロック**で、片方のアザミしか記録しなかった人の記録は固定される。+1.79と+2.47の分解は参照モデル上の会計であり、観察者と植物の因果的な寄与率ではない。

9,999回のラベル再割当てによる上側参照確率は、観察者を区別しない場合0.0053、観察者を固定した場合0.0049。**これは撮影者や植物を無作為割付した野外実験のp値ではなく、指定した記録ラベル交換モデルに対する診断値**である。帰無参照範囲を生物学的信頼区間と呼ばない。

## 単一の地域・観察者だけによる結果か

- 1地域ずつ除外しても観察者固定参照からの超過は **+0.55〜+3.28ポイント**で、全体平均の符号は残る。ただし各地域の超過は3地域で正、2地域で負であり、地域ごとに一様な効果ではない。
- 1観察者ずつ除く86回の診断では超過 **+1.18〜+5.94ポイント**。元の比較層を維持して計算したため、6件の層削除ケースでは元の10件基準を下回る。この診断を別の適格主標本と呼ばない。
- 同一観察者×同日×同植物×同昆虫×同地域の重複記録を減らすと、4地域155件に変わり、超過は **+2.14ポイント**。調査努力量を補正したことにはならない。
- 現在の昆虫種名・祖先名と一致する記録だけでも5地域190件、超過 **+2.47ポイント**。
- 5件閾値の探索的感度では、このペアは12地域432件、超過 **+2.56ポイント**。支持範囲が変わるため、上記の区間推定とは違う。

## 年・日まで固定した追加診断は事後探索として分ける

以下は主解析結果を見た後で追加した。191件の主比較層を固定したラベル参照診断であり、年・日を合わせた新しい標準化群集データを作ったわけではない。

| 地域・月の中で追加固定する区分 | 両種のラベルを交換できる記録 | 参照からの超過 | 上側ラベル参照確率 |
|---|---:|---:|---:|
| 年 | 140件、25ブロック | +4.35ポイント | 0.0011 |
| 観察者×年 | **41件、10ブロック** | **+2.20ポイント** | 0.0038 |
| 観察者×観察日 | **15件、5ブロック** | **+0.79ポイント** | **0.1157** |

同日比較で0.1157だったことは、頭花選別が存在しない証拠ではない。ただし、同じ撮影者が同じ日に両種を記録した情報だけで、対応の差を明瞭に区別できたともいえない。同じ2度セル・同じ日でも局所的な共存・同じ訪問経路・花の利用可能量は未確認。

前回同様、各種×地域×**同じ年・月**に10件を必要とすると対比0組。5件でも4組が各1地域しかなく、3地域以上の反復は0組。上の条件付きラベル診断によって、この不足が解消したと解釈しない。

## 対照的な別の種ペアと、主張の範囲

主条件の C. horridulum–C. nuttallii は2地域だけで探索的だが、観測Uは+10.62ポイントと大きい。しかし観察者固定参照の期待値が+10.46ポイントで、超過は **+0.16ポイント**にとどまる。見かけの種間対応の大きさを、そのまま植物の形態による選別の強さと呼べない具体例である。

今回の肯定的な成果は、**arvense–vulgareで、同じ暦月かつ観察者配分を考慮しても残る訪花者の記録上の対応**を定量化したこと。aza3の次の検証対象は、同日・同じ場所で両種の開花量と昆虫の利用機会を測った上で、その残りの対応が頭花の実測構造と接触・受粉成功に結びつくかである。季節、細かな生息場所、観察者の関心、花の量を、形態の効果へ無断で帰属しない。

Q1の系統記憶、Q3の色素再発現、298個体の将来計画、野外許可は変更していない。

方法の位置づけ: Gretton et al. (2012), *A Kernel Two-Sample Test*, JMLR 13:723–773, https://jmlr.org/papers/v13/gretton12a.html のMMDに対する等値カーネルの特殊例。ここでの式とブロック参照期待値は独立に導出・検算したもので、新規統計法や新しい野外観測としては主張しない。
