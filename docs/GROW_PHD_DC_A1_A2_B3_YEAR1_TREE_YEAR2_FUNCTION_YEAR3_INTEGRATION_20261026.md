# 京都大学 GROW 博士3年計画｜DC型 A①・A②（本体）＋ B③（発展）

**原著再確認・リスク回避・否定結果の論文出口（2026-10-26）:** [一次文献監査とGO/NO-GO代替計画](GROW_PHD_20261026_PRIMARY_LITERATURE_AUDIT_AND_FAILURE_CONTINGENCIES_V1.md)。既存Moreyra et al. 2025の350核座位系統樹との差別化が必要。RADは近縁集団を中心に、公開核系統で広域骨格を支える。向き×総苞防御が非支持でも雨保護・昆虫迂回・種子補償を競合検定し、十分な精度の反証と単なる測定不能を分ける。

更新日：2026-10-26。**申請用の研究設計**であり、新規のRAD-seq配列・野外測定や研究許可の取得を報告するものではない。

## 一つの問い
**アザミ属が新しい地域へ分布を広げる過程で、祖先の頭花形質は何度・どのように現れ、その組合せは送粉者と種子食者のもとでどのような繁殖上の利益をもつのか。** さらに、可視形質が消えた系統でもその形成能力の一部を保持するかを代表系で探索する。

- **A①：系統・歴史（必達／D1で解析を完成）**。分岐・放散年代と祖先状態、反復変化、頭花の向き×総苞の進化的連動／非連動、分布史の可能なシナリオ。独立の核RADと既存データを使用。
- **A②：適応的機能（必達／D2で主実験、D3で反復・統合）**。頭花の向き・総苞片/刺/粘着・ディスプレイが、送粉者の花粉沈着、種子食者の接近／産卵／直接損傷、母植物あたりの充実痩果をどう変えるか。
- **B③：祖先形質の潜在的形成能力（選択的発展／D3）**。代表する花色型または頭花形態の一系に限って、消失した表現型を構築する分子・発生資源が保持されているかを探索。誘導可能性やF1繁殖は必達にしない。

この分け方はA①とA②が科学的に独立の検証であり、両者を接続しても、過去の形質変化がその選択圧で生じたと**遡及的に証明するものではない**ことを明確にする。

## D1｜A①：年代付き核系統樹・祖先形質・反復変化の解析完成
**入力の確保：** 東京大学・伊藤元己教授から**提供予定**のアザミ試料の種名・標本ID・地域・保存法・採集/利用許可・DNA品質を照合し、既存の公開核系統・外群と統合。最初に24–48試料でRAD/GBS共通座位・遺伝子型一致率・制限酵素サイト脱落・倍数性混在をQC。広域系統は既存核遺伝子を重視し、集団解析は受領可能な重点系の複数集団で反復。既登録の「6系合計298個体」は将来の拡張目標であり、既採集試料やD1必達母数ではない。

**実行順：**
1. **前期**：標本・DNA・頭花形態の同一個体crosswalkとRAD pilot。GPS秘匿・分類群名と倍数性を管理。
2. **中期**：再現可能なSNPフィルタ、支持度/遺伝子樹不一致/集団混合を評価した核系統・ネットワークを構築。十分な母数がない集団は広域species treeではなく人口遺伝解析に限定する。
3. **後期**：公刊の年代較正が**正確な節点に対応づけ可能な場合のみ** dated topology ensembleを推定し、分岐年代と信頼区間を報告。公刊した0.93 Ma琉球分岐等を無関係な日本節点に強制しない。較正できない場合は**年代未解決**を明示して、枝長・相対史の推定を完成とする。
4. **年度末**：花色、**重力基準の向き**、総苞姿勢・刺・粘着性（該当個体で実測可能なもの）を多型・欠測を残して祖先状態推定（離散Mk/stochastic mapping/連続形質の感度）する。各形質の**反復変化数の分布・祖先状態の不確実性・系統間で同期した変化の支持/非支持**を提示。較正可能なら単位時間当たり形質変化率の比較も実施。
**D1必達成果：** バージョン固定した核系統樹/推定可能な年代付き樹、祖先形質地図、反復変化の推定と感度解析、D2機能試験の事前選定基準、系統・形態史を扱う論文原稿初稿。
**D1で主張しないこと：** RADだけで形質原因遺伝子・祖先の再活性化・正確な移住方向・適応・異例の進化速度を証明したとしない。祖先地域復元は地理・分散・絶滅の競合モデルの可能な範囲に限る。

## D2｜A②：向き×総苞・ディスプレイの適応的機能を初めて実測
**対象決定：** D1で系統上の位置、実際の向き/総苞の変異、送粉者と種子食者、採集・操作許可を事前点検した主対象**1種×2集団**。*C. purpuratum* は送粉/種子食研究がある候補だが、伊藤教授の提供試料と同一個体・分布進出関係を保証しない。**暫定実務規模：各集団25–30独立母植物、各植物2–3頭花＝計50–60母植物・100–180重点頭花**。頭花は植物内の反復であり独立系統数ではない。
**記録と因果鎖：**
- 蕾期から全調査頭花を登録（未産卵・非訪花含む）。頭花順位、花期、ディスプレイ（同時開花頭花数・季節小花数）、重力角、総苞片角度/間隙、真正な刺の長さ/硬さ、粘着・降雨/濡れを記録。
- 連続撮影の真の観察分母により、**送粉者**の接近→着地→柱頭への花粉沈着と、**種子食者**の接近→接触→侵入失敗・迂回→産卵→幼虫/直接種子損傷を区別。寄生蜂等の役割は独立同定の証拠がある場合にのみ認定する。昆虫目の機械分類は送粉者/食害者の機能同定ではない。
- 最後に同じ頭花の**食害成立頭花率、直接確認した損傷痩果率、充実成熟痩果数**と、植物全体の種子供給を分ける。いずれも実際の観察分母を示す。
**競合予測：** H2a 大きなディスプレイは植物当たりの送粉者訪問と種子食者曝露をともに増やす（最終成果は必ずしも比例しない）。H2b 向き×総苞は**相補的防御**または**代替的防御**を行い得る。H2c 向きの効果は種子食者排除でなく雨よけ/花粉保護である。H2null 花期・頭花サイズ・匂い/母植物資源が説明する。
**操作の識別範囲：** 場所と保全許可・安全性試験が満たされた場合は、**向きのみ**の非破壊的変更＋shamを独立母植物で無作為化し、**既存の総苞形態による条件付き角度効果**を検証。刺切除は組織損傷・匂い交絡のため安易に加えない。総苞の因果効果・完全な2要因交互作用は別の許可済み操作なしには主張しない。
**D2必達成果：** 同一植物・同一季節の到来/侵入/受粉/食害/充実痩果の新規データ、頭花構造の効果（介入が成立すれば因果、成立しなければ観察）とその不確実性、A②論文の主要図。

## D3｜A②の再検証とA①×A②統合／B③の限定的分子比較
**第一優先：A②を完了**
- D2で確立した方法で**翌開花期の独立コホート**を再観測し、可能ならD1で特定した**別系統／独立な形質変化**を予め固定して小規模に検証。できなければ同主対象の年差再検証を優先。
- A①で推定した向き・総苞の歴史的状態と、A②で現在の繁殖結果が支持する形態×昆虫/雨条件を対応させる。**「過去の進化理由」ではなく「反復形態が現在持つ条件付き適応価値」**として発表。
- **A②研究論文を完成**し、A①の系統史論文と合わせて博士論文の骨格とする。保留系統での予測・負の結果の判定を含める。

**第二優先：B③「潜在能力」だけを狙う1系の探索**
- D1から標本・花器官・白/着色や形態差の同一個体データが揃う系を1つ選ぶ（琉球*brevicaule / irumtiense*や多型* C. sieboldii*などから事前基準で選ぶ）。
- **花器官の色素化学・候補遺伝子発現・核祖先/倍数性**を同一個体で比較する。配列類似だけで機能的共同保持とはせず、白色の祖先状態と交雑/移住歴史を別に検討する。
- 実際の**再発現（共通園・誘導・交配）**と**世代を越えた維持**は別々の発展ゲート。多年生で博士3年中にF1開花・繁殖を確認できない場合は未実証とする。
**D3完了の判定：** A①の年代付き系統（条件付き）・祖先形質・反復変化＋A②の同頭花機能・種子生産・再現性を統合して提出。B③が不成立でもA区分の研究は完結する。

## 3年間の主要成果の定義と反証
| 統合問 | 肯定時に言えること | 否定/未識別のときに言えること |
|---|---|---|
| A① 反復頭花史 | 祖先状態と反復変化が異なる枝に配置される／独立系統でも類似形態が現れる | 多型/ILSで特定枝が未確定、年代較正ができず速度未推定、同じ形質が単一起源に限定 |
| A② 適応的機能 | 向き/総苞/ディスプレイが昆虫経路と充実痩果を変え、相手依存的利得がある | 単純な防御トレードオフは非支持、角度は濡れだけに作用、到来と種子成果が非対応 |
| B③ 形成能力 | 可視形質の抑制と分子機能資源の保持を代表系で区別できる | 試料・花器官機能・次世代が不十分な場合、祖先再発現と遺伝的維持は未検証として報告 |
