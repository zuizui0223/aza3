# aza3 Gate 0A — dated-tree readiness and recovery contract v1

**Status:** ACTIVE PREREQUISITE — NO RATE CLAIM AUTHORIZED  
**Date:** 2026-10-04

## Why Gate 0A exists

The Nature-scale aza3 programme asks whether the dominant Japanese *Cirsium* radiation accumulated capitulum diversity unusually rapidly.

That claim requires evolutionary time.

Current EAzami history is not time-scaled:

- the Japan38 accepted scaffold has branch lengths in substitutions per site;
- its 1,000 UFBoot trees are topology-sensitivity realizations, not chronograms;
- published broad age context exists, including a ~2.4 Ma Japanese founder/radiation context;
- local East-Asian dated studies provide some node-age anchors;
- but the exact machine-readable global dated tree used by Moreyra et al. (2025) has not been recovered publicly in the existing audit.

Therefore **no transition-per-Myr, disparity-through-time, or exceptional-evolvability claim is authorized from the current Japan38 phylogram alone.**

## Gate 0A question

> Can a taxon-reconciled dated topology ensemble be recovered or independently rebuilt well enough to support predeclared phenotype-accumulation rate tests?

## Route A — author/source tree recovery

Preferred route.

Attempt to recover the exact dated tree / underlying ML tree and dating outputs used by Moreyra et al. (2025), including:

- dated Newick or Nexus tree;
- exact taxon/sample labels;
- dating method output;
- calibration-node identities and constraints;
- any bootstrap/topology sensitivity material relevant to dating.

Acceptance requires:

- machine-readable tree;
- reproducible tip reconciliation to the admitted Japanese concepts;
- documented relationship between the recovered dated tree and the published analysis.

## Route B — independent dated reconstruction

Open only if Route A remains unavailable.

Use existing public sequence resources under a frozen rebuild contract.

Requirements:

1. use an explicitly versioned nuclear dataset;
2. preserve source sample identities and synonym reconciliation;
3. freeze orthology/paralogy and locus-retention rules before inspecting phenotype rates;
4. infer a topology compatible with the current broad phylogenomic evidence;
5. use published dating constraints only where their node mapping is defensible;
6. reproduce published temporal landmarks within a predeclared tolerance before using the tree for Gate 0;
7. propagate topology/dating uncertainty rather than retaining one preferred chronogram.

## Route C — local dated sensitivity only

If neither A nor B yields a defensible Japan-wide dated ensemble, retain local dated East-Asian subclades only as **sensitivity/context**, not as a substitute for the full Gate 0 rate test.

## Required output

A Gate 0A result must end in one of:

- DATED_ENSEMBLE_RECOVERED;
- DATED_ENSEMBLE_REBUILT_VALIDATED;
- LOCAL_DATED_CONTEXT_ONLY;
- NOT_IDENTIFIABLE.

## Gate 0B only opens after A passes

Only DATED_ENSEMBLE_RECOVERED or DATED_ENSEMBLE_REBUILT_VALIDATED permits the primary rate/disparity test.

Gate 0B must predeclare one primary statistic before phenotype-rate outcome inspection.

Candidate families:

- discrete state-change accumulation per unit branch time;
- functional/phenotypic disparity-through-time;
- novel capitulum-combination accumulation per unit time;
- branch-time-matched recurrence density.

At least one matched comparison is required:

- secondary Japanese histories;
- continental sister histories;
- branch/time-matched null on the admitted ensemble.

## What is already known and may be used as context

- 36/38 sampled Japanese concepts occur in one dominant radiation;
- orientation requires 4–6 minimum changes;
- phyllary posture requires 3;
- stickiness requires 5;
- these counts are lower bounds;
- relative lineage depth is not calendar time;
- broad Pleistocene age context is not a branch-specific transition clock.

## Falsification

The Nature-scale 'exceptional evolvability' premise fails or weakens if:

- no defensible dated ensemble can be obtained;
- or, after a dated ensemble is obtained, phenotype accumulation is not elevated relative to the frozen comparator/null.

Failure of Gate 0 does **not** invalidate the genomic-origin study of repeated phenotypes.

## Stop rules

- Never rescale the substitutions/site Japan38 tree by simply dividing by the published 2.4 Ma radiation age.
- Never assign published ages to guessed nodes.
- Never use one local East-Asian dated subclade as if it were the Japan-wide chronogram.
- Never choose the rate statistic after seeing which one yields acceleration.
- Never call the radiation 'exceptionally evolvable' before Gate 0B passes.
