# GROW D1｜東京大学から提供予定のアザミ試料：受領・解析可否の判断台帳

**2026-10-26／空テンプレート（試料未受領）。** 東京大学・伊藤元己教授からの提供は**予定**。標本数、試料、配列データ、許可の受領済みを意味しない。実際の試料が届く前に情報を捏造・仮登録しない。

## 入力台帳
[ヘッダーのみのCSV](../data/intake/grow_ito_sample_handoff_v1.csv) に、実際の引渡し情報を1資料／1由来個体単位で入力する。異なる小包・組織が同じ個体なら individual_id で連結する。正確な採集地点や氏名・連絡先など機微情報は**公開GitHubに置かず**安全な別台帳で管理する。deidentified_region には粗い地域コードを置く。

## GO/NO-GO 順序
1. **G0｜権利と分類**：voucher／もとの種名／採集年／元集団と、移転・配列・共有に関する許可を明示。権利未確認または保全上の制限がある試料を採集・破壊・解析したと見なさない。
2. **G1｜リンク精度**：標本IDとDNA個体ID、頭花画像の真正な対応を確認する。頭花とDNAが別個体なら、遺伝型×表現型の個体解析へは入れず、許される taxon-level 文脈に限定する。
3. **G2｜DNA・倍数性QC**：組織型と保存状態を確認後、DNA品質と倍数性を検査する。試験RAD 24–48試料は暫定目標であり合格や試料数が保証されているわけではない。共通座位・アレルdropout・paralogと反復一致率の閾値は結果を開く前に設定する。
4. **G3｜分析レーン**：
   - `BROAD_PHYLOGENY_REFERENCE`＝既存の350座位核系統を広域比較の基盤に使う。既存公刊樹を新規結果として再計上しない。
   - `RAD_POPULATION`＝十分な反復・共通座位を得られる近縁種／集団内で核祖先・混合・分化を解析。
   - `PHENOTYPE_TREE`＝voucherと頭花状態の対応が真正な資料で、祖先状態・反復変化の入力に使う。
   - `SOURCE_CONTEXT_ONLY`＝標本名・古い地点のみ等、個体遺伝連結がない参照資料。
   - `HOLD`＝許可・資料品質・同定が不明瞭なため解析に加えない。

## D1年度末の達成基準
- 核系統・集団史のうち、**新規試料と既存公刊系統の差分がどこにあるか**を明示。
- 年代較正が根拠づけられた場合は dated-tree ensemble／分岐年代と区間。そうでなければ `DATING_NOT_IDENTIFIABLE` と明記し相対史のみ。
- 頭花の向き・総苞・色・粘着は多型・欠測を保存して祖先形質・変化数の区間を報告。
- D2の野外対象は「予定通りの結果が出た分類群」ではなく、**操作許可・形態変異・相手昆虫・系統的独立性**の事前基準で選定。

## 今すぐ資料なしで実行できる部分
azami v4／EAzami／Moreyra 2025（DOI 10.1016/j.ympev.2025.108285）の既存標本・分類群crosswalkを整備し、SNP導入時の受け皿を作る。**提供済みと誤記しない**。新規RADが使えない場合は、公開核系統で頑健な祖先形質史の分布を示せるかを評価するが、同じ論文の単なる焼き直しを新規系統成果としない。
