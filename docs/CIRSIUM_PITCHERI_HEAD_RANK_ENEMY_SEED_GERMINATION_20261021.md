# Cirsium pitcheri：頭花の位置、ゾウムシ加害、次世代発芽の段階依存性

2026-10-21 | aza3 Q2 | **2つの既刊論文の実測報告を、出典と生物学的単位を分けて再解析したもの。** 原著の頭花・種子の生データや同一個体識別子を回収したわけではない。

## 1. 野外では頭花順位と食害が対応する

Gijsman, Havens & Vitt (2020), *Global Ecology and Conservation*, DOI [10.1016/j.gecco.2020.e00945](https://doi.org/10.1016/j.gecco.2020.e00945)。

Whitefish Dunes State Park（WFD）での *Larinus planus* による頭花加害痕の割合は、**頂端約27%、一次側枝約50%、二次側枝約80%**。著者概数の比は、一次側枝/頂端 **約1.85**、二次側枝/頂端 **約2.96**。同研究で加害された頭花は非加害頭花より成熟種子数が**約60%少なかった**。これらは観測による関連であり、真の刺長・総苞片姿勢・頭花重力方向・ゾウムシの無作為割付による因果比較ではない。位置(rank)は分枝次数・発育時期・サイズ・資源配分と絡む。公刊の概数から頭花数や効果量分散を逆算しない。

## 2. 次世代では頭花順位の利益が一様でない

Gijsman & Vitt (2021), *Ecology and Evolution*, DOI [10.1002/ece3.7109](https://doi.org/10.1002/ece3.7109)、原典[PMC表1](https://pmc.ncbi.nlm.nih.gov/articles/PMC7820163/table/ece37109-tbl-0001/)・[表2](https://pmc.ncbi.nlm.nih.gov/articles/PMC7820163/table/ece37109-tbl-0002/)の24セルを転記し、同年・同地点・同実験室温度で頂端対側枝のモデル発芽率を再計算した。

2016年は3度の寒冷処理を繰り返した**累積発芽率の最終フィット値**、2017年は別の母植物から個別追跡した**総発芽率モデル値**であり、同一デザイン・同一頭花ではない。SC=Ship Canal、WFD=Whitefish Dunes。以下は頂端−一次側枝の**公刊モデル点推定値の差**。

| 原採集年と地点 | 20/10°C 頂端/側枝 | 差 | 25/10°C差 | 30/10°C差 |
|---|---:|---:|---:|---:|
| 2016 SC | 0.828 / 0.197 | **+0.631** | +0.216 | −0.012 |
| 2016 WFD | 0.750 / 0.436 | **+0.314** | +0.188 | +0.023 |
| 2017 SC | 0.636 / 0.520 | **+0.116** | +0.120 | +0.101 |
| 2017 WFD | 0.360 / 0.393 | **−0.033** | −0.017 | −0.010 |

2016年の6条件では5/6で頂端の推定値が高いが、2017年は3/6。2016年WFDでは3温度すべてで頂端が高く、2017年WFDでは逆にわずかに低い。**これは推定点の符号差であり、有意な年×位置の交互作用ではない。** 原著も2017年WFDの発芽率で頭花順位の差を検出していない。モデル平均と周辺標準誤差から、元の個別試行・共分散・因果交互作用を復元していない。

20°Cでの頂端/側枝比は2016年SC **4.20倍**、2017年WFD **0.916倍**。20→30°Cへの発芽率下降幅（頂端 / 側枝）は2016年SC **0.767 / 0.124**、WFD **0.630 / 0.339**、2017年SC **0.281 / 0.266**、WFD **0.289 / 0.312**。発芽は実験室の操作温度であり、現地気候・頭花角度の直接応答ではない。

## 3. 研究上の重要な結果と停止条件

**支持：** 一つのアザミ種における頭花の発育上の順位は、昆虫の頭花利用、成熟種子生産、種子の発芽・温度応答と関連する。しかし各段階の大きさと方向は同じとは限らず、「一つの頭花形態が常に高い繁殖利益を持つ」という単純な機能値では整理できない。

**未同定：** 2020年の加害頭花と2021年に選抜された生存種子を**頭花IDで直接連結できない**。そのため食害率×成熟種子数×発芽率を掛けて**実生の純適応度**を推定してはいけない。2020と2021の同じ2016年親植物コホートに重なりがあっても、公開されたこの2表に個体IDの対応はない。温度・年・個体・順位・母性資源配分も絡む。

Q2にとって重要なのは、*rank* が既存の aza3 PR #68 の **重力基準の頭花の向き × 総苞片の開出**とは**別軸**だという点。真の「送粉者・種子食者の入口が変わる」というレゴ仮説を検証するなら、個々の頭花の rank、発育齢、サイズ、角度、外側総苞・本当の刺、昆虫の接近/失敗/迂回、独立確認した受粉・産卵、成熟充実痩果、可能なら同一頭花由来種子の発芽を**頭花IDで追跡する必要がある**。現段階で適応的レゴ、遺伝的独立、進化記憶の移植、失った色素形質の再発現は証明されていない。
