# aza3 Q2｜同じ粘着性頭花なのに、防御利益が検出される条件とされない条件はなぜ異なるか

**2026年10月24日｜アザミ *Cirsium discolor* と *C. flodmanii* の原著操作研究を直接対照。** この解析で新しく取得した野外頭花は**0**。2003年・2007年は原著出版社が公開している一次論文の抄録、1983年は元論文DOIと公開された著者抄録／引用情報を検証した。**本文PDFと個体別の頭花生データを検証済みとはしない**。したがって、存在しない試料数、効果量、p値、95%CIを捏造したメタ解析は行わない。

## 1．中心質問に対する新しい肯定的根拠と矛盾する証拠

> **花序外郭に防御機能を持ち得る部品が存在しても、その部品が実際に種子を守る利益を生むかは、昆虫の侵入口・種構成・タイミングによって条件付きになるのではないか。**

この問いに対し、**同じ *Cirsium discolor* でも粘着を妨げる野外操作の研究間で「利益の検出状況」が違う**という重要な実測先行研究がある。

| 著者・実験年 | 対象 | 元の介入 | 種子食害と繁殖結果の報告 | 証拠の上限 |
|---|---|---|---|---|
| Willson・Anderson・Thomas (1983)、1980年 | ***C. discolor***（米国イリノイ） | 粘着性総苞の分泌物を覆って機能を妨げる | **粘着を妨げると昆虫による種子食害が有意に増加** | 原著抄録による有意差。具体的p・試料数・無傷種子差は未検証 |
| 同じ1983年報告、1980年 | ***C. flodmanii***（ミネソタ） | 同様の分泌物被覆 | 明瞭な処理効果は**検出されず** | 異なるアザミ種・野外系 |
| 同じ1983年報告、1982年 | ***C. flodmanii***（ミネソタ） | 同様の分泌物被覆 | 明瞭な処理効果は**検出されず** | 同一種の再調査。ただし独立な進化起源ではない |
| Thomas (2003)、1982〜1987年の調査 | ***C. discolor*** および別属 *Penstemon digitalis*（イリノイ） | 花序の粘着を中和 | **種子食者が増えたり種子形成が減ったりする**という仮説は支持されなかった | 原著の抄録は両種の結果を総括。*discolor* の年別・個体別帰属や統計値は未検証 |

[1983年 *American Midland Naturalist* 原著 DOI 10.2307/2425228](https://doi.org/10.2307/2425228) ／ [2003年 *The Great Lakes Entomologist* 原著 DOI 10.22543/0090-0222.2085](https://scholar.valpo.edu/tgle/vol36/iss2/3/)。

これは**「1980年には粘着構造が利益を持ち得る実験結果があるが、その利益は異なる種・時期の試験で常に検出されるわけではない」**という、実際の自然史に基づく主張である。

**ここで言ってはいけないこと：** 2003年の検出不能を「粘着の効果＝厳密に0」としたり、1980年から1982〜87年に向かって選択係数が正から負へ変化したとしたりすること。1980年と1982〜87年は同一個体でも無作為抽出された独立環境反復でもない。1983年の分泌物を覆う操作と2003年の粘着中和操作の**同等性も未確認**。時期・対象昆虫組成・植物群落・実験法は交絡している。

## 2．同じ粘着面が、どの昆虫に実際に接触されるか

続く Thomas (2007)、[DOI 10.22543/0090-0222.2188](https://scholar.valpo.edu/tgle/vol40/iss2/8/) では、*Cirsium discolor* および *Penstemon digitalis* の花序を使う節足動物を直接観察している。

| 接触相手 | 実際に報告された挙動 | 植物側の利益を言えるか |
|---|---|---|
| 訪花送粉者 | 粘着部位には**接触しなかった** | 「送粉が起きなかった」ではない。受粉成功の独立測定は必要 |
| 一部の種子食者 | 粘着部位を**回避して頭花を利用できた** | 防御構造があっても、真の敵の侵入をゼロにできない |
| ナガカメムシ類などの小型捕食者、ハエトリグモ類 | *C. discolor* の粘着に捕らえられた虫を**拾い食いするように見えた** | 種子食者を捕食して無傷種子を増やしたとは未実証 |
| アリ・アブラムシ類 | 粘着により**妨げられた** | これらが種子食害を起こしたと証明されたわけではない |

**新しい生態学的な整理：** 「外側に防御部品があるか」ではなく、実際の昆虫が**どの入口を使うか**、そもそもその昆虫が植物の有効送粉者・真の種子食者・非種子食の盗蜜／摂食者・捕食者のどれなのかが、防御から実際の繁殖成果への変換を左右する。

これは直接観察された昆虫接触からの機構仮説であり、2015年 *Pedicularis rex* の水を保持する苞葉への介入で食害が増加した野外操作研究とも整合する。ただし**苞葉の水保持と粘着性アザミ総苞は同一器官の相同な部品でも、同じ操作でもない**。*Pedicularis* では6種子調査集団中4集団が当方の6検定BH補正後も有意な食害差を残し、訪花数が測定されたのはShamaの1集団だけ（p=0.958、有意差なし≠同等性）。

[2015年 *Pedicularis* の原著統計・多重補正と本来のサンプル単位](PEDICULARIS_REX_TWO_ACCESS_OPERATORS_ORIGINAL_FUNCTIONAL_EVIDENCE_20261024.md)。

## 3．だから「トレードオフ」のあり方も単純な形に限らない

**仮説 H-gate：相手別ポータル使用仮説。** 頭花の粘着・刺・総苞片・下垂角という見かけの形態が変わっても、正の送粉者が接触しない安全な入口から花粉搬入を行い、真の種子食者も防御を回避して産卵できるなら、見かけの防御形質の効果は**アリや偶発的な小型訪問者を排除するにとどまり、無傷種子数への利益が小さい**可能性がある。

逆に、当該集団の真の種子食者が粘着・刺・総苞の影響を受ける入口しか通れない状況では、**外側の部品が害を減らして繁殖に寄与する**可能性がある。ここで敵集団組成が変わると、同じ形態が持つ**機能的な利益の強さ**も変わり得る。

これを **「特定の外側部品に恒常的な適応価値がある」vs「相手と環境に依存した、複数の条件付き経路に分かれる」**という検証可能な対立にする。ただし現時点でH-gateの昆虫種頻度・防御成功率・個体適応度への媒介分解は直接推定していない。

## 4．アザミで初めてこの問いを決めるための実測デザイン

既に [PR #86で統合した**連続録画分母・昆虫接近レコード**](AZA3_Q2_REAL_HEAD_FUNCTIONAL_ACCESS_MAINLINE_20261023.md)に、同じ頭花の真の防御形態と最後の種子成果を結ぶ。

| 同一頭花で記録する段階 | 最低限必要な実測と、帰無 |
|---|---|
| 形態 | 重力基準の頭花角度、総苞片の開きと間隙、校正された刺・粘着強度、頭花年齢と開花段階。**別植物の種平均で代用しない** |
| 接近の分母 | カメラ稼働・全接近（未接触も含む）、撮影死角、付近の他アザミ花頭数、同じ地点・同じ日の昆虫候補の分類・努力量 |
| 相手の接触と成功 | 真の送粉者候補は花柱／柱頭への接触と花粉着床、種子食者候補は入口試行・産卵の有無・時刻、捕食／寄生者は初期加害より前の阻止を実測 |
| 繁殖成果 | 同じ頭花で胚珠数、種子食害の直接目視・無傷成熟痩果、必要なら発芽。種子数を昆虫の直接利益と自動同定しない |
| 対立仮説 | (A) どんな昆虫群集でも同じ外側形態は常に防御利益、(B) 相手の侵入口使用や時期により利益が変動、(C) 形態ではなく開花量・植物資源・環境が主な差を説明 |

この測定が進むまで、「粘着有無×種子食者侵入×花粉形成×無傷種子数」という**同じ頭花・同じ昆虫介入の因果モデル**を実行済みとは呼べない。保全管理・採集・昆虫操作の明示的許可は依然必要である。
