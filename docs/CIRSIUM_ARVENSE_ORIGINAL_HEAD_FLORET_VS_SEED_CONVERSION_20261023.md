# aza3 Q2｜頭花あたり種子数の減少は「小花数」か「良好種子形成率」か

**2026-10-23。既存野外実験の新しい原データ計算。** *Cirsium arvense* の2022年の著者オリジナル615頭花、Karpate et al. 2025 Research Square **preprint** [DOI 10.21203/rs.3.rs-6634172/v1](https://doi.org/10.21203/rs.3.rs-6634172/v1)、[Zenodo 10.5281/zenodo.15364152](https://doi.org/10.5281/zenodo.15364152)、[著者GitHubの固定 seeds.csv](https://github.com/Yogita25/Multitrophic_Interactions/blob/8a151c62ed069f775a16b9bc5fbdce209cbb8691/seeds.csv)。

## 結論：袋掛けの下では「小花数の差」でなく小花あたりのViable_Seeds割合の差にほぼ対応する

前回PR #82で、36対応ブロック全てで袋掛け処理の著者判定「良好種子」割合が開放対照より低く、羽化昆虫も減ることを確認した。今回は、良好種子の**絶対生産量／頭花**を、原著の小花計数と種子分類率に分けた。比較は前回と全く同じ36ブロックに固定し、4地点（campus12、construction9、ditch8、rapseed7）の処理前の標本を後から入れ替えない。

同じ site×block×treatment の推定「処理植物」について
- X = 原著列 `Flowers` 合計 / 記録頭花数（頭花あたりの著者Flowers計数）
- p = 原著列 `Viable_Seeds` 合計 / 原著列 `Flowers` 合計（良好種子割合）
- Y = `Viable_Seeds` 合計 / 記録頭花数 = X p（頭花あたり良好種子数）

2処理A/Bの実数差は、**完全な恒等式（対称Kitagawa/Shapley分解）**で書ける。

\[
Y_A-Y_B =
(X_A-X_B)\frac{p_A+p_B}{2} +
(p_A-p_B)\frac{X_A+X_B}{2}.
\]

第1項を「Flowers数差成分」、第2項を「良好種子率差成分」と呼ぶ。**これは遺伝・形態部品・花粉受精に帰属する因果的効果量ではない**。元データの `Flowers` は処理前に計測した器官サイズや全蕾数とは証明されず、`Missing_Seeds` は符号付きの原著算術残差である。

### 同一36 site-blockの平均（A−B）

| 処理差（単位は良好種子数／頭花） | 袋掛け−対照 | 捕食者排除−対照 |
|---|---:|---:|
| 元著者の良好種子／頭花差 Y | **−41.59** | −3.82 |
| **Flowers数差成分** | −0.33 | −3.77 |
| **良好種子率差成分** | **−41.25** | −0.047 |
| 原著Flowers／頭花の差 ΔX | −1.31 | −5.82 |
| 良好種子割合の差 Δp | −0.523 | −0.006 |

袋掛けの数値では、−41.25/−41.59＝**99.2%**が**数理分解上**の率差成分。花粉生理・昆虫・微気象のどの作用の寄与が99.2%かを意味しない。対照的に捕食者排除の−3.82はほぼFlowers数差−3.77に対応し、率差は0に近い。ただし頭花／Flowers数は実験処理後に成立した計数で、処理によって形態や頭花構成が変化したかは識別できない。植物サイズ、花序ステージ、サンプリング条件の差もあり得る。

### 不確実性を元地点内36ブロックから計算

原著4地点を固定したまま、各サイト内の完全ブロックを**10,000回再標本化**した、原標本条件付きの記述的95%区間：

| 袋掛け−対照 | 平均 | 95%区間 |
|---|---:|---:|
| 良好種子数／頭花の差 | −41.59 | [−46.77,−36.26] |
| Flowers数差成分 | −0.33 | [−2.16,+1.36] |
| **良好種子率差成分** | **−41.25** | **[−46.56,−35.77]** |
| Flowers／頭花の差 | −1.31 | [−7.13,+4.08] |
| 良好種子割合の差 | −0.523 | [−0.587,−0.456] |

袋掛けの良好種子率差成分は4地点それぞれで負（campus −44.53、construction −35.37、ditch −50.02、rapseed −33.19）。Flowers数差成分は4地点のうち2地点で負、2地点で正。これは「観測された頭花の小花数減少が全地点で共通の主原因」という読みと整合しない。

**注意：** これは独立に無作為化された植物単位を確認した因果信頼区間ではなく、既存サイト・ブロックに条件付けた再抽出区間。615頭花を615の独立な実験植物として計算していない。単一サイトの結果を属全体の複数独立な放散と誤用しない。

## もう1段階：良好種子率が下がったことを「被食増加」と呼べない

元CSVの原著カテゴリー定義は `Flowers = Viable_Seeds + NViable_Seeds + Damaged_Seeds + Missing_Seeds` を、615頭花すべてで満たす。最後の `Missing_Seeds` は負の行が存在する**帳簿的残差**。したがって、袋掛け−対照の良好種子率差−0.523は、カテゴリー恒等式では次のように分かれる。

| 元の分類別割合（袋掛け−対照） | 平均差 |
|---|---:|
| 目視非良好種子割合 `NViable_Seeds/Flowers` | **+0.389** |
| 目視損傷種子割合 `Damaged_Seeds/Flowers` | **−0.036** |
| 符号付き残差 `Missing_Seeds/Flowers` | **+0.170** |
| 良好種子割合 `Viable_Seeds/Flowers` | **−0.523** |

単純な分類上の「非良好種子」の増加と残差の増加が、良好種子割合の減少と帳簿的に対応する。**目視損傷そのものは平均でむしろ小さく**、「袋掛けで種子が少ないのは幼虫に食べられたから」という説明を、このデータだけで認定してはいけない。逆に「送粉失敗だけが原因」とも言えない。`NViable_Seeds` の中に受精失敗・発育障害等がどの程度含まれるかは、独立した花粉付着／胚発達アッセイがない。

## 次の生態学的主張の形

**観測事実：** アザミの頭花内で、繁殖出力の変化は少なくとも「形態・Florets計数」「良好種子への換算」「損傷と残差」という複数ステージに分かれ、同じ昆虫アクセス介入でも、どのステージに大きな差が出るかは一様でない。

**Q2 仮説（今後の実証）：** 本物の頭花向き・総苞片・トゲ・粘着性が相互作用相手に応じて**接触→小花への有効花粉搬入／産卵→被害前胚形成→充実痩果・発芽**の異なる段階に寄与し、その条件に依存した利益が部品の組合せにより変わる。現実の形態操作と独立した相手の入口失敗／送粉有効性の同じ頭花IDがなければ、この仮説を「検証済み」と呼ばない。

既にaza3の別サンプルにある ***C. acaulon / bertolonii / erisithales*** の同一植物114頭花形態と、今回 ***C. arvense*** の612適格頭花には、**種も植物IDも共通しない**。花冠・総苞片と小花率を恣意的に個体レベル結合して、形態が機能を予測したという偽の結果にしない。

次に取るべきデータは、現場権利・保全許可を得た同一植物で、①処理前の頭花・小花数と正しい姿勢、②総苞・刺の物理形状、③送粉者と種子食者の接触／不成功、④その頭花の花粉付着・受精と充実種子、⑤発芽をIDで連結すること。新しい野外実験も植物の採集も本PRでは実施していない。
