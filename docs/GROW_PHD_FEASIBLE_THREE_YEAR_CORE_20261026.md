# GROW博士3年間の実行可能な中核計画（2026-10-26）

**位置づけ**：申請書向けに既存の巨大なaza3研究構想をD1〜D3に縮約する研究運営方針。実測済みの成果ではない。伊藤元己教授の試料提供は**予定**であり、受領済みとみなさない。野外操作の許可も未確定。

## 一つの主題
**アザミが新しい地域へ進出するとき、頭花形質はどのように変化してきたか。その形態は送粉と種子食害を通じて繁殖上どのような利益を持つか。**

**必達研究（博士論文の2本柱）**
1. **Q1・歴史**：RAD-seq＋既存核系統で集団／系統を比較し、祖先形質・分布進出の競合史を評価する。
2. **Q2・適応的機能**：一つの確かな調査系で頭花の向き・総苞片と昆虫アクセス、受粉・食害、最終充実痩果を同じ頭花に結びつける。

**重点予備研究**：Q3は「可視形質がなくても、形質を作る分子資源が残っているか」を、白花・着色など実在する1系で試験する。真正な再発現と世代を超える維持は、採材と発育周期による**発展的問い**であり、D3の納期条件にはしない。

**本計画の重要な変更**
- 「1年RAD、2年野外、3年巨大なRNA/WGS/世代実験」という直列計画はしない。**D1にD2の蕾～昆虫予備観察とQ3試料保存を開始、D2はD3の再調査余地を残す。**
- D1でどの地域が「祖先域/進出先」か決まらない場合でも、機能実験自体は完成できるよう**系統史の歴史的識別と現地適応的機能を別々に設計**する。
- Q2ではディスプレイ規模・頭花角度・総苞片を一度に操作しない。第一の介入は**角度一軸＋sham**、総苞姿勢は自然変異から確認する。完全な向き×総苞の因果相互作用を主張するには別の操作設計が必要。
- 最終アウトカムは**母植物／頭花ごとの成熟充実痩果**。食害成立頭花率、直接損傷痩果率、羽化昆虫／産卵数は別指標。直接種子食害が確認できない場合の計数残差を「食害率」としない。
- **伊藤教授提供予定の保存試料**と、**新規に現地で行動・繁殖を調べる母植物**は、確認したIDが同一の場合にのみ結合。必要ならQ1系統骨格とQ2現地主対象は別の系でも構わない。その場合、機構の直接接続を誇張しない。
- 形質の祖先的再発現は、形態の再出現・祖先型経路の再利用・遺伝・世代間の維持を区別する。博士3年では**保持の検証が最小の堅実なQ3成果**である。
