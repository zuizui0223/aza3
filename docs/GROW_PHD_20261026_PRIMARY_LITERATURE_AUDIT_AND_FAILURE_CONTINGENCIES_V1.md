# 京都大学GROW博士計画：原著監査・困難時の代替案・反証時の論文出口（2026-10-26）

## 判定を先に
**A①系統史＋A②適応機能＋発展B③潜在能力**という骨格は維持するが、主張の強さと実施可否は現状では別。**原著確認の質は不揃いで、完全なsystematic reviewを実施したとは言えない。** D1において「これまで存在しなかった新しいCirsiumの系統樹をつくる」と書くのは避ける。広域核系統樹は既存のMoreyra et al. 2025を骨格として、伊藤元己教授から提供予定の実標本が持つ**系統・地理・頭花形質の同一個体リンク**により形質史と集団史を実際に検証することを差別化の核とする。

**文献監査の未完了事項**：
- 複数形質（向き×総苞・刺）と送粉・食害の**同じ植物・同じ頭花での操作**を済ませたCirsium論文を網羅的に探索する必要がある。現時点で**確認できなかった**が、「存在しない」と宣言しない。
- 1983年の粘着研究、2025核系統の原補助ファイルと正確なdated-tree、国内アザミでの花器官色素・共通園/遺伝実験の補足資料を追加監査する。
- 既存メタ4研究のRR＝2.674［2.388,2.993］は食害を減らした場合の種子生産**背景値**であり、向き・刺・総苞の選択係数ではない。
- 新たな研究を行う前にMethodsやsupplementの原データ単位、処理割付、統計量、検出力を原論文ごとに再確認する。

## 3. 実際に事前設定する「GO/NO GO」項目
D1開始前：供与者との試料台帳、DNA/形態同一個体対応、適切な標本識別、倍数性・保存条件／使用権。公開の350座位核系統を復元可能な背景に置く。

D1前半：24–48試料RAD試験。正確な数値合格閾値は技術条件・配列数に基づくoutcome-blind QCで事前決定（ここで任意の「共通座位80%」等を捏造しない）。

D1末：核系統樹と配置不確実性、**分岐年代が較正可能かの判定**、祖先状態と各形質の反復変化範囲、系統間変化の共定位感度、事前登録された野外対象。

D2初期：最低限の相手同定、母植物と蕾からの観測、角度操作が本当に角度のみを変えるか、sham/保存倫理、実際の昆虫イベント・種子判定精度。**最小生物学的関心効果（SESOI）とpilotからの分散を用いて事前シミュレーション検出力を算出**し、支えられない交互作用は探索扱いにする。

D2末：次年度の再検証・結果報告ルールを効果の正負に関係なく固定し、主解析は`head access`と`plant-level viable achene yield`の2本柱。

D3：独立年/母植物反復。B③はA区分の成果を犠牲にしない単一系限定の探索。

## 4. 「否定的結果」の4分類
1. **真の反証**：適切な対照と十分狭いCIにより、事前設定した意味のある効果が除外される。これは論文の中心的科学的結果になり得る。
2. **対立機構の支持**：刺・向きより雨/花粉・花資源・捕食者迂回でよく説明できる。主仮説は不支持でも明瞭な仕組みの論文になり得る。
3. **効果の異質性**：年・地域・相手による方向・大きさの条件付き変化。単純な一方向理論より価値がある場合がある。
4. **測定不能（NOT_IDENTIFIABLE）**：提供試料がない、撮影できない、敵がいない、検出力不足、正しい較正がない。これは負の生物学的結果ではなく、次の識別可能な問いへ優先順位を変更する根拠。

## 5. 審査書に入れる簡潔な保険文
「本研究では初年度に提供試料の品質・倍数性・共通座位の回収率を確認し、必要に応じて公刊核ターゲットキャプチャーデータを系統骨格、RAD-seqを近縁集団の分化解析に分担する。年代推定は較正可能な節点に限定し、祖先状態と形質変化には系統的不確実性を伝播させる。野外実験は種子食者の存在・形態変異・操作安全性を予備調査で確認した後、送粉者の花粉沈着、昆虫の侵入・直接食害、植物当たりの充実痩果数を別々に測定する。防御効果が検出されない場合も、雨からの花粉保護、昆虫の侵入経路の迂回、種子生産の補償という競合機構を検証する。発展課題の祖先的形成資源の分子検証が難航しても、主課題である形態進化史と適応的機能の研究を完遂する。」
