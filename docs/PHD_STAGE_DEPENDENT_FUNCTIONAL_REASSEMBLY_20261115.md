# 博士研究：発育軌道 × 機能的補償の進化（v1, 2026-11-15）

**状態：事前設計（新しい生物学的観測・RAD-seq解析・野外操作は未実施）。** これは[核系統・BM/OU・自然対照の博士主線](PHD_PHYLOGENY_BM_OU_NICHE_NATURAL_CONTRASTS_20261115.md)を深掘りする付属仕様であり、研究課題を追加して肥大化させない。発育の時間軸は、従来の「向き O」について個体内反復計測するだけで、主形質軸は O と総苞 B（開出・**真正のトゲ**）。粘着Sは別の補助的機能軸である。

## 中心問題（形態の収斂に対する一段深い問い）
「同じ頭花の形を作ること」と「同じ繁殖機能を実現すること」は一致するか。また、蕾・開花・結実の機能的要求が異なるとき、**頭花の向きの発育軌道**と**総苞構造の組合せ**はどのように分化しうるか。

主張したい結果を事前固定しない。競合する4機構：
- **T（時間的分業）**：蕾・開花・結実で頭花角度 `O(t)` が変わり、種子食者と送粉者に対して曝露時期がずれる。変化が産卵後なら「産卵阻止のための下垂」という説明は失敗しうる。
- **C（機能的補償／many-to-one mapping）**：同じ最終繁殖成果に達する複数の O×B 組合せが存在する。強い総苞防御で追加的な下垂の防御利益が小さくなる（代替）ことも、両者の相乗もありえる。**同じWを持つ形態があっても、その同等性は十分な精度で確認する必要**がある。
- **E（環境・相互作用レジーム依存）**：同じ気候で形態が異なる場合、実際の昆虫ギルドが違えばその機能が異なり得る。植物・昆虫の共通観測地点を必須とし、GloBI種リストをその地点の実現ギルドとみなさない。
- **M（非適応的機械・発生拘束）**：頭花重量・花柄剛性・位置・発育段階で O が受動的に変化する。BとOの関連も頭花サイズと共通発育機構の産物であり、機能的適応の直接選択を必要としない。Mを必ず競合仮説に置く。

**順序**：まず歴史→比較進化→自然対照・操作。単なる現在の二重機能から外適応・機能転用の歴史的方向を復元しない。機能転用の歴史を主張するには古い系統段階の機能推定や複数系統の比較が必要であり、D3で保証しない。

## 1. 生物学的に異なる測定軸
一行=特定の植物個体×頭花ID×測定セッション。繰返し測定を独立頭花と数えない。
- `O_bud`, `O_open`, `O_fruit`: 鉛直上向き=0°, 水平=90°, 鉛直下向き=180°の頭花軸角度を、同一頭花IDに対応づける。枝・花柄の相対角と頭花の重力方向を**別々**に記録する。時刻・雨・開花齢も記録し、発育に伴う動きと短時間の天候反応を混同しない。
- `ΔO_early=O_open−O_bud`、`ΔO_late=O_fruit−O_open`。各量の母植物・集団内分散も記録する。対応が実測できなければ「進化した発育軌道」は未識別。
- `B_opening_deg`, `B_gap_mm`, `spine_tip_projection_mm`, `spine_rigidity_assay`, `stickiness_assay`。真正の刺と総苞片の開出・粘着を混同しない。Bも蕾と開花では異なり得る。
- `mechanical_covariates`: 頭花質量（可能なら非破壊代理）、花柄長/直径・剛性代理、頭花3D縦横比、頭花の枝順位・付着点、個体サイズ・花期、雌性/両性などの繁殖型。
- `interaction_exposure`: 実際の有効動画時間と観察ゼロ時間、昆虫同定の確実性、到来・着地・**真の総苞刺接触**・迂回・産卵・幼虫侵入・有効な柱頭花粉沈着を段階ごとに別々に記録。
- `fitness`: タグ頭花の成熟充実痩果/頭花、検査した痩果の直接損傷比率、別試料の発芽可能性。植物全体Wを言うのは全頭花数と採種収量を適切に推定できた場合だけ。

## 2. 核系統解析からマクロ進化へ何を引き渡すか
**広域（D1）**：Moreyra et al.（2025, 350核座位）の同定・樹形・年代付き木の出典と適格性を再点検。既存EAzamiは日本38概念で向きの状態変化最低4–6、総苞姿勢3、粘着5を示すが、これを「刺の進化」へ読み替えない。
**近縁（D1）**：許可済み・同個体voucherのRAD-seqを追加して集団構造・交雑・近縁関係を調べる。RADの共有座位不足・倍数体混在・パラログ・参照バイアスの場合は公刊核骨格とRAD集団解析を別レーンにし、枝長を不正に連結しない。
**形質進化（D1→D2）**：
- 花期の O と真正Bをまず主解析。樹アンサンブル＋種内分散/測定誤差を通した離散ASR (Mk) / 連続祖先分布を使う。
- 次に、**発育軌道**（ΔO_early / ΔO_late）の系統比較を、十分に独立した種のstage-linked個体データがある場合のみ追加。キセルアザミなど2種の権威記載だけで「発育軌道のBM/OU結果」を装わない。
- BM1を基準とし、OU1、環境別OU、複数速度BM、多変量BM/系統補正回帰は事前定義された必要十分な独立レジームのときのみ。見かけのOU支持は祖先への「引力」や適応度最適値の実証ではない。測定誤差・サンプル数・モデル誤選択をパラメトリックシミュレーションで評価。校正年齢がなければ枝長当たり変動のみ（per-Myrやdisparity-through-timeは不可）。
- 環境ニッチは採集の**開花期・地点**に合う降水・日射・温度・湿度と観測努力・分布背景をもつ。BIO18の年季節を花期雨の直接原因に置き換えない。系統PGLSや環境/形態距離の関係で候補を絞る。
- 昆虫の「相互作用ニッチ」は自然対照で実際に測ったギルドしか用いず、気候ニッチだけが現在の頭花機能を説明するという対立仮説を残す。

**モデル選択のGO/NO-GO**：別系統の状態変化数、同stage実測種数、環境レジーム独立反復、樹不確実性、形質欠損、操作単位の独立性を数え、識別力不足ならOU多レジーム／形質相互作用の試験を`NOT_IDENTIFIABLE`として外す。選択されたモデルのAIC値だけから適応進化を宣言しない。

## 3. 自然対照群の優先度と結び付け方
最初は[6比較の固定表](../data/planning/cirsium_phd_natural_contrast_panel_20261115.csv)を使用し、追加で[発育軌道スクリーニング表](../data/planning/cirsium_phd_stage_trajectory_screen_20261115.csv)を用いる。
1. **最優先 N01 オハラメアザミ種内**。NMNSは `C. kiotoense` に下向き～斜上／稀に直立、粘着強弱・刺の有無強弱・雌性/両性を記載。**それらが同一種・同一性型・同じ開花ステージの同所頭花に両立して存在するかは未確定**。自然のO×Bが重なる範囲（positivity）がなければ、2形質の独立作用を自然対照だけで推定不可。
2. **最優先 N03 キセルアザミの種内型と発育**。`C. sieboldii` は点頭して開花し花後直立、直立開花型も知られる。**直立開花型と通常型を同一発育段階で比較**して発育軌道の違いと機能差を探る。花後直立を開花直立型へ混入させない。
3. **N02 オハラメアザミ×カガノアザミ**。科博は北陸で同所生育を記載するが、調査地での実際の同所・同時開花は未検証。`C. kagamontanum`は固定Japan38 tip外。**昆虫群と地理を揃えた種間比較**、系統/サイズの差が残ることを明示。
4. **N04 キセルアザミ×ヒダキセルアザミ**。湿地生育だが分布が重ならず、`C. hidapaludosum` は蕾～結実で直立。**自然同所対照ではなく、発育軌道と環境の類似性を試す非同所準対照**。核祖先・標高・気温・花期の交絡を解決しない限り適応差の因果とは呼ばない。
5. **N05 C. dipsacolepis×C. lineare**。既存核樹の近縁対だが焦点は**粘着性**で、真正の刺対照とは別。形質差と産地の実測が成立した場合のみ総苞の予備比較に使う。
6. **N06 C. muratae**は分類群追加と頭花形態の独立性確認に位置付ける。未同定・保全・花期制約なら延期。

**pilot判定**：同じ場所/開花期/性型/発育段階でOとBの実際の重なりがあるか、昆虫ギルドが実在し十分観察できるかを先に確認。採集人数・本試験検出力の確証はない。既存GROWのP0写真投影較正、P1真のARと被覆、P2蕾期の産卵時点というゲートを先に通す。

## 4. 反証可能な判定表
| 仮説 | 支持方向の観察 | 独立した反証・識別不能要因 |
|---|---|---|
| **時間的分業 T** | 向きの変化が送粉と産卵の異なる実際の時期と対応し、相手別アクセス率も変化する | 向き変化が敵の産卵後に限られる；ギルドの時系列が未観察；同じ機能が全段階で維持 |
| **機能的補償 C** | 同じ曝露条件でO×Bの相互作用があり、別組合せの種子損失が機能上同等または逆転 | 実際のBとOに独立変異がない；サイズ・性型で消える；区間が広く同等性不明 |
| **相互作用ニッチ E** | 気候・系統・性型を揃えても相手群の違いと形態の機能利益が対応する | 実際のギルド差がない；頭花数/開花時刻/微気象が説明；実測不十分 |
| **機械的・発生拘束 M** | 質量・支持剛性・花齢がO/B共変動を説明し、独立の機能効果が再現しない | 安全な角度操作で即時の受粉/濡れ/敵アクセスが変わり、異なる集団で再現する（Mだけでは不十分） |

**主たる因果実験は増やさない**：
- D2 1つ目：同一母植物の類似発育頭花を**非損傷・許可済み**の向き変更 vs sham に無作為割付し、**有効柱頭花粉沈着を主要機構量**、充実痩果を植物繁殖成果として測定。来訪回数だけで機能的選別とはしない。
- D3 2つ目：蕾期の実際の産卵者・総苞接触が確認され、無損傷操作と適格な比較数・許可が確保できた場合に限り、総苞入口・粘着の**最大1処理** + sham。真正刺自体を切断して傷害と防御を混同しない。成立しなければ自然B変異と敵行動の観察のみ。
- `O×B` と `O×stage` は**副次機構**としてpilotの独立母植物数・イベント率に基づく条件付き検出力を評価し、識別不能なら正式な主要検定に上げない。処理後の着地数は媒介であり、無造作に一次全効果モデルの共変量へ入れない。

## 5. 3年間の実行順・論文出口
**D1**：資料受領/権利・系統骨格・必要な集団RAD・O/B形質のASR。自然対照のstage-linked観察pilotを並走。成果：系統史と形態の分離・連動を論じる論文。
**D2**：同じ形質のBM/OU/ニッチの適格比較（モデル性能による縮約）＋一つの向き×送粉・雨の因果実験。成果：環境対応と機能の条件付き関係。
**D3**：別集団・翌年再現＋敵の有無に応じ総苞の機能を最大1操作か自然対照に限定し、個体繁殖成功へ接続。成果：形態・発育・相互作用の機能統合論文。

**現在解決していないこと**：Stage-linked個体データ、伊藤教授からのRAD試料受領、候補の同所・同時開花、訪花・産卵ギルド、年代付き核樹、野外許可と保全枠、BM/OUの実際の適合度。これらは新しい肯定結果ではない。
