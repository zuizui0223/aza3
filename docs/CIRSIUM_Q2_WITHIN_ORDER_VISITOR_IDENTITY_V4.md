# Q2：アザミと訪花者の対応は、チョウかハチかを揃えても残るか？

**2026-10-20 | 実ソース再解析・事後探索的検証 | aza3**

## 結論（肯定的な範囲と未識別な範囲）

**同じ5つの2度グリッド・暦月にある実際の191訪花記録で、植物種ごとの昆虫種名の対応は、記録した観察者と昆虫の目（Lepidoptera/Hymenoptera等）の両方を固定したラベル参照モデルでも残った。** ただし、同じ日に両アザミへ訪れた昆虫の実測、頭花への真正接触、有効受粉、頭花構造の選択的利益を実証したわけではない。

出所はGloBI（2026-10-08スナップショット）に統合されたiNaturalistの明示的な**成虫の訪花関係**3,243固有観察であり、以前の[種×地域×月の観察者固定解析](CIRSIUM_WITHIN_SEASON_HOST_ASSOCIATION_RESULTS_V3.md)と**同じ事前に選ばれた191観察**を厳格に維持した。標準化訪花調査の191回、独立した訪花成功191例、実際の花粉媒介191例ではない。条件は2度セル・同じ暦月・各植物種10記録以上、3地域以上で比較できた唯一の `Cirsium arvense` と `C. vulgare`（**5地域月、191記録、86観察者**）。以前の513件の「3種×共通5地域」集団を季節補正したものとみなさない。

## 1. 粗い目の組成にも違いがある

| 公開DBの訪花関係記録 | *C. arvense* | *C. vulgare* |
|---|---:|---:|
| Lepidoptera（チョウ・ガ目） | 95/107 = **88.8%** | 65/84 = **77.4%** |
| Hymenoptera（ハチ目） | 8/107 = **7.5%** | 18/84 = **21.4%** |
| Coleoptera/Diptera | 4/107 = 3.7% | 1/84 = 1.2% |

同じ5地域月のそれぞれを**同重み**にしたハチ目記録割合は *arvense* **6.10%**、*vulgare* **23.02%**。差 (*vulgare − arvense*) **+16.92ポイント**。観察者ごとのアザミ記録数と昆虫の目の内訳を固定した場合の期待差は **+8.60ポイント**、差は **+8.32ポイント**。この差は5地域月中、4つで正・1つで負だった。撮影件数は花の利用可能量、訪花頻度、昆虫の種子食害や送粉効率で補正されていない。「ハチ目」には生態的役割の違う種が含まれ、全てが有効送粉者とは限らない。

## 2. 昆虫の目を固定した種名一致の差

二つの実際の観察で昆虫種名が一致する確率から、**同じ植物種内の一致確率平均 − 異なる植物種間の一致確率**を計算した。観察を自分自身と比較しない半等値カーネルMMD²の不偏推定量 `U`（有限標本で負値も取り得る）。場所×暦月の5層を同重みとした。

| 同じ191記録の種名一致 `U` | 値 |
|---|---:|
| 観測 `U` | **+0.042563** |
| 観察者ごとのアザミ記録数を固定した参照期待値 | +0.017902 |
| **以前報告した観察者条件付きの超過** | **+0.024661** |
| 観察者に**加えて昆虫の目**を固定した参照期待値 | **+0.028579** |
| **さらに目を固定しても残る超過** | **+0.013984** |

観察者単独の超過量の **56.7%** が、観察者×昆虫目の固定参照後に残るという*会計上の比*である。差 **+0.010677** は「目の構成を追加で固定したとき参照期待値が上がった分」だが、原因寄与率・真の送粉者選好の媒介効果ではない。全191件中、観察者×昆虫目ブロック内で植物ラベルを交換できるのは **46記録／11ブロック**だけ。他の単独宿主の記録は条件付き参照では固定される。

固定計数に従う49,999回のラベル再割当てで、観測 `U` 以上の上側参照確率は **0.0283**。**この参照モデルは前の結果を見て追加しており、事前登録された仮説の検定でも、独立調査の無作為化p値でもない。** 複数の後続比較を探索したうえでの条件付き診断値としてのみ残す。

### 種名の違いをどの目が担っているか

もとの種名別・細分類カウントを基に、固定観察者×昆虫目の参照期待値を**各昆虫種名ごとに厳密な超幾何分布の2次モーメントで分解**した。全部足すと+0.013984へ戻る。今回の「目を固定した後の超過」は、記録上は**Lepidoptera内部の訪花者種名の組成から生じた**。Hymenopteraの寄与は、この観察者×目ブロックでは0。これはハチの植物選好がゼロという意味ではなく、ハチ目内で観察者・宿主を交換できる比較情報が乏しいためである。

種名別に大きな正の寄与は *Pieris rapae* **+0.006693**、*Papilio glaucus* **+0.002935**、*Argynnis cybele* **+0.002895**。*Danaus plexippus* は **−0.003659**と、同じ宿主を同定する差を弱める方向。これらは**数学的な寄与であり、昆虫がその植物を実際に選好した強さではない**。昆虫の個体識別もできず、同一個体の別写真や種誤同定が全て解決されたわけではない。

Lepidoptera記録だけ160件、元と同じ5地域月の下で種名一致を再比較すると、観測 `U=+0.035559`、観察者固定参照`+0.007270`、超過`+0.028289`。ただし、Lepidopteraだけに絞ると宿主別記録数が変わるので、191件の推定対象との効果量比較を因果的な「分割寄与」とは呼ばない。

## 3. 特定の1地点・1昆虫だけが作った差か

- 元の5地域月の**1地域ずつ除外**：観察者×目の固定参照からの超過は **+0.00844〜+0.01944**。
- 58の記録昆虫種名を**1種ずつ除去**した固定層診断：超過は **+0.00818〜+0.01991**、58/58で正。ただし **6/58** の除去では元の「各宿主≥10記録」の条件を満たさなくなった。新しい主推定対象へ昇格しない。
- 昆虫種名の影響がもっとも強い *Pieris rapae* の14記録を除外しても超過は **+0.00818**。数値は残るが、観察者割付・記録選択の独立な再実験を保証しない。

**厳格な同じ観察者×同日の昆虫目固定参照では交換可能なのは15記録だけ**で、超過は+0.007904。前段の同日条件のラベル診断も明瞭ではない。したがって「時間を完全に揃えた植物選好が確認された」は依然**未同定**。同月でも異なる年・日・2度セル内の微生息地が混在する。

## 4. aza3の機構仮説として使える範囲

**観測的に支持：** 同じ大まかな地域・暦月で、*C. arvense* と *C. vulgare* に紐づく訪花者記録は、目の組成およびLepidoptera内部の種名構成の両解像度で一致しない傾向を示す。

**未同定：** 頭花の向き・刺・総苞の真の接触部位がこれを作ったか、各昆虫が有効送粉者／種子食者／捕食者／寄生者としてどう機能したか、植物の種子繁殖成功の符号、異なる選択最適値、適応的な遺伝的LEGO、失われた花色の再進化。

ここからの実証は、観察者の投稿記録を増やし続けるのでなく、**同じ日に共存・開花する個体群**で、植物×頭花ID、開花量、実測角度・総苞・刺、昆虫の実種・接触位置・花粉機能と最終充実痩果を同時に測定すること。元の保全・所有者・採集・昆虫操作の正式許可は一切未取得。`Q1`の外部系統記憶・`Q3`の分子的再到達可能性は本分析で推定しない。
