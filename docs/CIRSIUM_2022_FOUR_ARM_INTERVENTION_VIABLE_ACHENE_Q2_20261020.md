# Q2実測：Cirsium arvense の4処理は頭花の生存種子を同じように変えるか？

2026-10-20。**2022年の公開野外実験615頭花に立ち戻り、既存の二群比較を四群・完全対応ブロックへ拡張した二次解析。** 自前採集ではない。原著の効果を新発見と呼ばない。

## 実施・固定された原資料

Karpate et al. (2025) *Research Square* **preprint**, [10.21203/rs.3.rs-6634172/v1](https://doi.org/10.21203/rs.3.rs-6634172/v1)。著者の2022年チェコ共和国4地点の同一研究。生データ [Zenodo 10.5281/zenodo.15364152](https://doi.org/10.5281/zenodo.15364152)、[著者公開GitHubの固定コミット](https://github.com/Yogita25/Multitrophic_Interactions/tree/8a151c62ed069f775a16b9bc5fbdce209cbb8691)、`seeds.csv` Git blob `ca99c762162d15f006f0c73b4603ca71fd320a29`。

原本615頭花、解析可能な612頭花、site×block×treatmentに由来する**164推定母植物群**、45サイト×ブロック、4処理を全て含む**36完全ブロック**（campus12、construction9、ditch8、rapseed7）。著者原稿中の個体ID／頭花数との厳密照合には残課題があるため、site×block×treatmentを**確定の母植物IDではなくproxy**として扱う。**頭花を独立の処理反復に数えない。**

対象4処理の原著上の意味：
- **Control**：通常開放。
- **Pollinator Exclusion**：複数頭花にorganza網袋を設置。花粉到達だけを特異的に操作したわけではなく、昆虫接近、微気象、袋への接触も変わり得る。
- **Predator Exclusion**：茎の粘着トラップ、定着捕食者の手動除去。植物自身の総苞片・刺を外した実験ではない。
- **Predator Model**：実際の捕食者除去を継続し、その上で緑色の人工クモ模型を設置。「捕食者を追加した」処理ではない。

原著の設計説明は同じブロック内の第1植物=対照、第2=袋、第3=捕食者除去、第4=模型と記しており、**植物への無作為割付の独立確認はできない**。これらを差の記述ではなく自然界の因果効果と断定しない。

## 4処理に揃えた36ブロックの原データ結果

各proxy群で先に `sum(Viable_Seeds) / sum(Flowers)` を計算してから、同じブロックの処理差を取る。3頭花の植物と5頭花の植物を同じ観測数として扱う、**母植物近似単位の対照差**。観察単位と分母を無断で入れ替えない。

| 同じ36ブロックでの処理 | 平均生存種子割合差（対照との差） | 正/負のブロック数 |
|---|---:|---:|
| Pollinator Exclusion | **−0.5231** | 0 / **36** |
| Predator Exclusion | **−0.0059** | 17 / 19 |
| Predator Model | **＋0.0225** | 13 / 23 |

同じ36ブロックで **Pollinator Exclusion − Predator Exclusion = −0.5171**。これも36/36ブロックが負。したがって送粉者排除と捕食者除去の差を異なる比較可能なブロック集合の違いだけでは説明できない。結果はもとの `Pollinator Exclusion−Control` 39組 −0.5091、`Predator Exclusion−Control` 40組 +0.0043、`Predator Model−Control` 38組 +0.0186 から、**共通比較36組**への移行によっても大枠が維持された。

## 観測変数の違いが相互作用経路を左右する

同じブロックの生存種子割合が大きく変わっても、そのまま昆虫の「食害効果」を推定できない。原データの `Missing_Seeds = Flowers−Viable_Seeds−NViable_Seeds−Damaged_Seeds` は独立に観察した種子食害ではなく**計数上の残差**。原本615頭花中、`Missing` が負の頭花80、`Damaged+Missing` が負の頭花62。直接観察の `Damaged_Seeds`、種子成立 `Viable_Seeds`、羽化昆虫 `Insects` を分離して全て出力する。原著の `Eaten=Damaged+Missing` の増減は独立な生物測定ではない。

**肯定的だが限定的な結果：** 対応した四群では、送粉者を排除する複合処理に関して生存種子割合が一貫して非常に低く、捕食者の取り扱いを変える処理では比較全体の平均は小さく、ブロックごとに正負が混在する。これは繁殖の利益・費用を**アクセス相手と生態段階ごとに分ける必要性**を示す実データ上の手掛かりである。捕食者の生物学的効果が本当にゼロである証拠ではなく、同じ頭花の構造的な刺が機能する証拠でもない。

## 比較単位・感度・将来の真正な識別

- 各比較はsite×block**内で対応**をとり、全4サイト別平均・leave-one-site-out・leave-one-block-outを保存。36完全ブロックでsite内に保った5,000回のブートストラップを加えるが、各地点・群に条件付けた標本感度であり、独立な進化起源・厳密な因果区間にはしない。
- 腕ごとの測定頭花数が異なる。**頭花で直接重み付けした全体平均**は母植物レベルの対照差と異なる推定対象。
- 原著から計算した指標は「著者の生存種子分類」であって、別個の発芽実験ではない。
- これらの処理には**頭花の重力基準の向き、実測刺長、総苞片間隔、昆虫の接触経路**の操作がない。捕食者回避模型が実際に昆虫に見えたかを頭花別に検証した資料もない。
- **Q2の決定的な次段階：** 実物の総苞・刺・向きを同じ頭花で実測し、同種同時刻で来訪昆虫の接近→接触→侵入→独立検証した受粉/産卵→最終的な成熟充実痩果を対応させる。これまで設計した[PR #44](https://github.com/zuizui0223/aza3/pull/44)の真の物理的アクセス分母を使う。生態的な結果が出る前に適応的LEGOと呼ばない。
- **Q1 / Q3：** 系統間の進化的記憶・潜在的色素再発現をこの単一年同種データから主張しない。独自フィールド観察・採集・許可は未取得。
