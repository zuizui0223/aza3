# Cirsium：進化が到達できる生態的解の多様性 v1
2026-11-15｜仮説・判定ルール。**新しいRAD実測、野外観察、適応の証拠ではない。**

## 主問題

**交雑・倍数化・祖先変異の選別は、頭花の形態の選択肢だけを増やすのか。それとも、送粉者の利用と種子食者の回避を両立できる生態的な「解」の選択肢も増やすのか？**

RAD-seq は系統樹だけでなく「どんな祖先構造・遺伝子流動を通じて、異なる形態の組合せが実現したか」の調査に使う。独立した頭花機能実験をつないで初めて「生態的に有利な解」に踏み込める。

*本研究の候補概念は「形態の選択肢の増加」と「生態的な解の増加」を分離することである。* 交雑や倍数化をすべて適応進化に結び付ける仮説ではない。

## 先行研究との差

1. **交雑が適応放散を助け得る**ことは既知である。Schumer & Rieseberg 2026, Nat Rev Genet, https://doi.org/10.1038/s41576-026-00995-7; Stone & Wessinger 2024, Mol Biol Evol, https://doi.org/10.1093/molbev/msae007。
2. **異なる形態が同じ機能を実現する many-to-one mapping**も既知。Evolution 2017, https://doi.org/10.1111/evo.13357。
3. **多形質×多機能の理論**もある。J Theor Biol 2024, https://doi.org/10.1016/j.jtbi.2024.111744。
4. **花の遺伝構造・組合せ選択**にも新しい総説がある。New Phytologist 2026, https://doi.org/10.1111/nph.71605。
5. **交雑と倍数性が種の境界を越える**場合も研究されている。Mol Ecol 2024, https://doi.org/10.1111/mec.17315。

したがって上記単独は本研究の新規発見ではない。**RADでの祖先構造・組合せの成立と、同一個体／頭花の複数機能・繁殖適応度を対応づけた「実現可能な有利な組合せ」の検定**を新しい貢献候補とする。

## 独立な2つの推定対象

### G：genomic origin / accessible observed configurations

- *同一個体*の RAD核DNA、集団、cytotype、真正な頭花O（重力角）・B（総苞間隙）・T（本物の刺）・S（粘着）を測る。
- まず集団・系統・発育段階・体サイズを調整した観測形態の組合せ範囲を比較。記録された形態分布の広さは、遺伝的に**実現可能な全組合せ**の広さではない。育成／交配試験がなければ「accessibility」は控えめに**実際に観測された構成の範囲**と呼ぶ。
- 形態差がcytotype・混合祖先に対応しても因果効果ではない。交雑、祖先多型、polyploid/homeolog、de novo のどれかをRADだけで確証しない。
- 倍数性の効果を検証するには、個体別倍数性、複数の独立なcytotype変化、近縁系統の対照と観測機会の統制が必要。2xと4xを1組比較して「polyploidy promotes diversity」とは言わない。

### F：ecological solution / functional performance

「送粉・敵害」をまず**別々の2成分**で測る。

- P = 同等の花齢・観察努力条件における**有効な同種花粉沈着／受粉成功**。訪花回数は代理しない。
- E = 蕾期・開花期を区別した**確認産卵／直接種子損傷**（低いほど良い）。検出なしを敵不在と解釈しない。
- W = 同一頭花の**成熟充実痩果数／必要なら生存可能性**。送粉や敵の効果が最終繁殖結果に届くか確かめる。試験間の種子数と捕食率を掛け合わせてWを作らない。

「Pareto的な改善」と呼べるのは、事前定義した同じ生態的文脈・同じ発育窓で、ある形態のPが悪化せず、Eが改善（またはその逆）し、少なくとも一方が明確に改善する場合である。Wは別の最終検査にする。単なるPとEの負相関や形態多型はそれ自体では適応ではない。

**機能的冗長性**の主張は「形態が大きく違うがP、Eが事前固定の生物学的同等性幅に含まれ、可能ならWも同等」である場合のみ。検定が非有意なだけでは同等ではない。同等性幅は機能結果を開く前にpilot分散・生物学的重要差・測定精度に基づき固定する。

## 生物学的に区別する4モデル

| モデル | 観察予測 | 反証／支持の境界 |
|---|---|---|
| **C：共通制約** | O/B/T/S は祖先構造・発生段階・植物サイズから主に決まり、組合せ空間は狭い。Pの増大はEの増大を伴う | 相同の背景内で独立の組合せが十分再現し、複数の機能到達経路を示せれば弱まる |
| **R：形態的冗長性** | 大きく違うO/B/T/Sが統計的に同等な(P,E,W)を達成 | 実際のP,Eに再現的な差があり同等性の事前幅を外れれば弱まる |
| **X：トレードオフの緩和** | O×B/T/Sなどの組合せが、同じ文脈の対照よりPを保ちEを下げる。Wも減らない | P低下がE改善を上回る、W悪化、別集団で再現しないなら弱まる |
| **S：文脈依存の選別** | 同じ頭花形態のP/E/W順位が、送粉者・敵・降雨の組合せで変わる | 十分な環境反復でも相互作用が乏しければ支持が弱まる |

**モデルは完全に排他的ではない**。例えばR（同じ文脈での冗長性）とS（別の文脈での選別）が共存し得る。両立と排他の意味は推定対象・環境を固定して判定する。

## 現在の真正な証拠と限界

- EAzami V10：若い日本放散でOは4–6、総苞姿勢3、粘着5の最低変化回数。3組のペアで頑健な共通遷移位置0/3。**遺伝的モジュールや適応の証明ではない**。
- EAzamiの9分類群に染色体・cytotype記録。主放散の8分類群では2xが5、4xが2、6xが1。判明した向きの主放散7分類群で、二倍体にも上向き・下向きがある。**倍数体の形態多様性増大を推定できる標本数・独立事例数ではない**。
- 現行aza3の新RAD個体台帳、直接頭花形態台帳、昆虫接近・観察努力台帳は空。**同一DNA個体×頭花の有効花粉沈着×産卵/損傷×充実痩果の結果は0件**。
- Azamiの写真由来角度は重力角でなく、輪郭は撮影投影に依存。両者は直接の機能測定にならない。

よって**本研究の新規核心は現状まだ仮説**である。

## 検証の最短ルート（RAD中心の既存主線を崩さない）

1. **D1技術pilot**：同一RAD法で24–48試料の技術試験（採集済み個体数ではない）。2x/多倍体、異なる系統、標準対照を含め、共有座位・allele dropout・homeolog・欠損率・再現性の事前QCを判定。
2. **独立対照ペアを設計**：同種内O/Bの違いがある集団・近縁別種対照で、voucher・形態・cytotype・RAD個体IDを一致させる。先に正確な系統・発育窓・観測機会を定義し、遺伝的に似た系統の形態差／形態が似る異系統を選ぶ。
3. **同じ頭花に機能を結ぶ**：既存の `capitulum_guild_access_event_ledger` と動画努力台帳を使い、別途 **同種花粉沈着の直接測定**と**成熟痩果の本物の結果**を新規台帳で登録する。花粉の破壊測定と種子検査は同じ小花でなくても良いが、どの頭花か結び付ける。
4. **検定**：観測形態の組合せ範囲（形態空間）→同一文脈での2成分機能空間(P,E)→Wに届くか、を別々に解析。効果がなければ冗長性仮説を同等性検定する。単なる「差が有意でない」は無効。
5. **遺伝機構の深掘り**：RAD構造と形態・機能の関連が複数独立集団で再現したときのみ高密度再シーケンス、必要なら発現解析で遺伝子交換・祖先変異・倍数性の寄与を分離。

## この設計のストップルール

- **同じDNA個体と頭花を照合できない** → genomics–function連結は停止。
- **送粉者と敵の観測努力が不明** → 有効率／不在の推定停止。
- **真の花粉沈着または種子損傷・成熟種子が未測定** → Many-to-one・Pareto・適応の主張停止。
- **2xと多倍体の独立反復がない** → 倍数性による制約解放の因果主張停止。
- **形態群で発育齢・母植物サイズ・撮影投影が一致しない** → 形態×機能の原因推定停止。
- **RAD SNPはあるが稠密な特定領域と実際の選択がない** → adaptive introgression / causal gene の主張停止。
- **操作者・採集者・土地管理者の許可がない** → 野外採集・操作・シーケンス発注は停止。

## 判定の最終形

**有望な強い結果：** 異なる核ゲノム祖先／混合・cytotypeを持つ個体で、相同の形態的選択肢が再現し、少なくとも一部のO×B組合せが他の組合せより実測P維持＋E減少を満たし、Wにも反映される。さらに起源を特定できれば「genomic route → viable ecological solution」の証拠になる。

**同じくらい意味のある別結果：** 遺伝的な複雑さが形態だけを増やし、機能は冗長である。この場合「形態的多様性は機能的多様性の代理にならない」という一般則に関与する。

**失敗ではない反証：** 形態も機能も系統・倍数性・成長段階だけで説明され、RADの祖先混合度に追加情報がない。この場合「ゲノムの複雑さが新たな生態的解を作る」というモデルは棄却方向。

これは**既知の「多形質モジュール」「交雑」「many-to-one」を単に組み合わせた結論ではなく、どのモデルが生態的な実測を最もよく説明するかを独立に判定する計画**である。結果が出る前にNature級の新規性を断言しない。
