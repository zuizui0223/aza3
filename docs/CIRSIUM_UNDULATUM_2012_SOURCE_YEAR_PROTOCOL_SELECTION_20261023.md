# aza3 Q2｜「枝途中の種子が少ない」の一般化を阻む二重の選択と実験方法の年差

**2026-10-23：真正USDA公開元データの追加解析＋原著者の2012年学位論文の再確認。**
対象：*Cirsium undulatum*、West & Louda 2021 [AJB DOI 10.1002/ajb2.1744](https://doi.org/10.1002/ajb2.1744)、USDA元データ [10.15482/USDA.ADC/1522649](https://doi.org/10.15482/USDA.ADC/1522649)。観測頭花は2007–2008年。現時点の実証は第三者の野外研究の原行データ再解析であり、新規の野外観察・遺伝解析は0。

## 1. 生態学的に解釈を変える結果：20組は106株の代表ではない

前回 [PR #80](CIRSIUM_UNDULATUM_NESTED_BRANCH_SEED_HURDLE_20261023.md) は頭花位置コード（200↔210、300↔310など）に対応した20組から、2008年では5/9組が「枝先のみ良好種子形成」、3/9組は両方、1/9組は両方ゼロという二段階の繁殖結果を得た。

**ただしその20組は106母植物中14株だけに偏る。** 対応できるのは2007年7/39（17.9%）、2008年7/67（10.4%）。対応可能な個体は同年内の非対応株より、良好種子総数も記録されたロゼット径も大きい。

| 母植物を単位とする原データ | 2007年 | 2008年 |
|---|---:|---:|
| 元の母植物数 | 39 | 67 |
| 枝先・枝途中が両方記録された母植物 | **7** | **7** |
| それ以外の母植物 | 32 | 60 |
| 対応可能個体：株あたりgood seed平均 | **102.57** | **147.71** |
| 非対応個体：株あたりgood seed平均 | 54.31 | 81.75 |
| 対応可能個体：ロゼット径平均 | **37.14 cm**（7/7に値） | **30.14 cm**（7/7） |
| 非対応個体：ロゼット径平均 | 29.17 cm（29/32に値） | 22.06 cm（49/60に値） |

これは「枝途中の形成が適応的に繁殖を高める」「大きい株だから位置差が生まれた」という因果主張ではない。**2種類の頭花位置が実際に成立・記録されたという処理後の条件への選別**を含む。未形成の位置を種子数0として元106株へ補完しない。元CSVのロゼット径の測定時点も十分に確証できないため、確定した処理前共変量として使わない。

### 年×実験処理群ごとの元の分母

ndi＝頂端損傷なし＋殺虫剤、ndni＝頂端損傷なし＋通常植食圧、di＝頂端損傷あり＋殺虫剤、dni＝頂端損傷あり＋通常植食圧。数字は「対応可能な母植物数／元の処理群の母植物数」。

| 処理群 | 2007年 | 2008年 |
|---|---:|---:|
| ndi | 1/10 | 1/21 |
| ndni | 1/9 | 1/15 |
| di | 4/11 | 3/19 |
| dni | 1/9 | 2/12 |

元の処理割付からみても、枝位置を対応できる率は群によって異なる。対応後の頭花だけに「植食者の有無」「頂端損傷の効果」を因果的に当てはめない。

## 2. 2012年博士論文：年差は実験方法の差も含む

[West (2012), *Herbivory affects patterns of plant reproductive effort and seed production*, University of Nebraska](https://digitalcommons.unl.edu/bioscidiss/41/) 第2章のExperimental Design／Data Collection（印刷61–64頁、PDFゼロ起点68–71頁）を確認。2021年の論文と同じ元研究に関する著者の一次史料であり、追加の独立試験ではない。

| 設計／測定 | 2007年 | 2008年 |
|---|---|---|
| 植食低減に使った薬剤 | acephate、1%溶液との記載 | bifenthrin、0.06%溶液との記載 |
| 散布間隔 | 7–10日 | 14日 |
| 頂端損傷 | 昆虫を封入・穴あけ、必要に応じて茎を部分的に切断 | 同様の虫処理区に加え**機械的損傷のみ**の区も導入 |
| 頭花位置の反復観察 | 2週間ごと | 4週間ごと |

溶液%は有効成分の効果量として直接比較できない。**年・自然環境／自然植食圧・薬剤／損傷方法・観測頻度が同時に変わった。** 年による種子数差から生態環境だけの効果や頭花構造の防御力の進化を結論できない。

同論文 Fig. 2.2の凡例（公開PDFページ87）は「2.5等の半整数位置が特定の枝の末端頭花より下側の subordinate heads」であることを明記する。よって元CSVのx00／x10には**同じ枝の階層である実体的裏付け**がある。ただし各現物の枝連結が写真と原IDで再検証できるわけではなく、重力基準角度・総苞刺・開花順とは異なる。

## 3. 一株から複数枝を独立個体としない感度解析

2008年の枝コード対応9組は「末端のみgood seed」5、「途中のみ」0。ただし同じ母植物に複数の枝があるので、9組を独立な9株として検定するのは誤り。

**母植物ごとに最小位置コードの1組だけを採用**すると7独立母植物は「末端のみ4／途中のみ0／両方2／両方ゼロ1」。不一致4組を等確率とする探索的な両側二項基準は **p=0.125**。「最大コードの1組を採用」すると末端のみ5／途中のみ0／両方2で **p=0.0625**。このpは無作為に配置した頭花の因果検定ではなく、小標本における**対称性の参考値**。同じ元データでも1株1組の選択で値は変わる。元のPR #79の6件の事後探索テストBH q=0.09375を撤回して「位置効果は有意」と再宣言しない。

2007年も1株1組ルールで途中だけ種子ができた組の有無が変わる。頭花番号の大小を生物学的な開花順番とみなさない。

## 4. Q2の肯定的示唆と次の実測ゲート

**肯定的な帰結は、構造的に別の位置へ繁殖出力を分散しても、各頭花が成熟良好種子を作れるとは限らず、形成可能性／種子形成の可否／形成した場合の量／次世代成功が別々の段階だと、真正データで確認できたこと。** これを相手依存の適応的LEGOという証拠に読み替えない。

aza3独自の次の実証では、既に計画された許可・保全条件を守り、全ての対象母植物（枝途中の頭花が形成されない株も含む）と全頭花を時点ごとに追跡する。母植物ID・枝の連結・各頭花ID・形成／開花・頭花サイズ・総苞と刺の実測・送粉者による有効柱頭接触・植食者の産卵／侵入・良好種子・発芽を紐付ける。昆虫処理と頭花構造の操作を許可された場合に初めて、相手によって頭花形態の機能利益が反転するかを因果検証できる。

本結果はQ2の識別可能性を明確にしたもの。Q1の系統間形質記憶、Q3の消失後遺伝的再利用はいずれも未証明。野外で新たに取得したサンプル・観測は0。
