# 頭花の間接防御はどこまで「逆転」できるか：昆虫の移動による反例

2026-10-08 | Focus: *Cirsium* capitulum structure × head-entering seed feeders × late parasitoid enemies. Companion to `CAPITULUM_LATE_PARASITOID_GENERATIONAL_FEEDBACK_V1.md`. All parameters and numerical effects below are **hypothetical, not observations**.

## 前回の主張を狭める必要がある

前回の単一閉鎖パッチモデルでは、頭花の防御が現在の種子食者の侵入を減らしながら、損傷後の寄生蜂殺傷を抑制し、地元に残る種子食者の次世代数を増やすと、長期の頭花種子被害が逆転することがあった。

しかし **移動する昆虫は「この頭花由来だから次世代も同じ頭花形態を選ぶ」と限らない**。初期防御成功と長期の地域被害は別の因果量である。2パッチ間の混合は予測を根本から変える。

## 対立する頭花群集モデル

等しい大きさ・頭花密度の2つのパッチを定義する。0は外壁障壁なし、1は外壁障壁あり。地元に定着した種子食者が種子を不可逆的に食べた**後に**寄生蜂に殺される割合がそれぞれ `q0`, `q1` とする。障壁によるその世代の侵入定着率の比を `r<=1`、局所個体群を再生する係数を `K` とする。外部から両方へ毎世代等しく `I>0` が供給される。

潜在的到来個体の圧力を `A0[t], A1[t]`、繁殖後の子孫のうち**相手パッチへ分散して次の攻撃機会を持つ割合**を `m in [0,0.5]` とする。等しい繁殖資源・同じ宿主レース・同じ頭花発育期に限る最小モデル：

```
k0 = K(1-q0)                   # baseline patch recruitment
k1 = K*r*(1-q1)                 # armoured patch recruitment
A0[t+1] = I + (1-m)k0*A0[t] + m*k1*A1[t]
A1[t+1] = I + m*k0*A0[t] + (1-m)k1*A1[t]
D0[t] = d*A0[t]
D1[t] = d*r*A1[t]              # d equal per damaging seed-feeder
```

安定な十分条件 `k0<1, k1<1` の下で解析解は

`D1*/D0* = r[1-(1-2m)k0]/[1-(1-2m)k1]`。

したがってパッチ被害の長期逆転に必要十分なのは

**`(1-2m)rK(q0-q1) > 1-r`**。

- `m=0`: 以前の閉鎖パッチ式に一致する。
- `m=0.5`: 完全混合のため、同じ到来圧力にさらされる2パッチの相対被害は**必ず `r`**。晩期寄生蜂が地域全体の種子食者を増やしても、障壁のある頭花は常に条件つきでは有利になる。
- `q0<=q1` or `K=0`: 機能反転なし。
- 低い障壁コストがあっても、形態の「自然選択への符号」はパッチの相対被害とは別に測定が必要。

### 予測される分散閾値（仮想例）

前回と同じ `r=0.7, K=1.2, q0=.6, q1=.1` では、反転するための分散条件は

`m < (1 - (1-r)/(r*K*(q0-q1)))/2 = 1/7 ≈ 0.142857`。

| 次世代が他パッチへ移る比 m | 長期の障壁あり/なし被害比 | 帰結 |
|---:|---:|---|
| 0% | 1.492 | 防御パッチで被害が多い |
| 5% | 1.244 | 同上 |
| 10% | 1.091 | 同上 |
| 14.3% | 1.000 | 境界 |
| 15% | 0.987 | 防御パッチで被害が少ない |
| 50% | 0.700 | 直接防御の30%減と一致 |

すべて**モデル設定から生じた値**。実際のアザミの飛翔昆虫の移動率、帰還率、次世代繁殖寄与、寄生蜂の有効死亡率が実測されているという意味ではない。現実の混合は方向・距離・季節・宿主植物の位置・昆虫種・隣接頭花の存在で異なるため、単一の `m` に収まる保証もない。

検算プログラム：`analysis/check_capitulum_enemy_feedback_migration_v1.py`。独立の連立一次方程式解・解析解を突合し、0%、完全混合、境界、安定外挿拒否、無帰還反例をテストする。

## これがアザミ頭花の進化研究に何を意味するか

**生態的な見かけ上の逆転を自然選択と誤認してはいけない。**

あるパッチに防御形質をもつ植物が多いほど、寄生蜂が妨げられて次の世代の食害者が増えるとしても、その昆虫が周辺の他の植物型にも分散する場合、当該パッチの現在の平均被害は**遺伝子型の直接適応度**にならない。とくに単回繁殖型の *Cirsium palustre* は、その植物個体が翌年も頭花を作るわけではない。

同じ昆虫到来圧力 `A` に暴露した個体の直接的な雌性繁殖成功を、極めて制限的に
`W0=B-dA`, `W1=B-C-drA`
（共通の潜在種子数B、障壁の直接的繁殖コストC、障壁以外の花粉制限なし）とすれば、
`W1-W0=dA(1-r)-C`。
局所群集で晩期寄生蜂が減っただけでは、W1-W0の符号を決められない。さらに花粉輸出や花粉沈着が障壁と向きで変わればBはそもそも共通ではない。

自然選択の決定には同じ虫圧の下で、*real spine length / stiffness / direction × true head orientation × access guild* の組合せごとに、受粉、産卵、寄生蜂行動、最終充実痩果・発芽を記録する必要がある。形態の同期進化にはこれに独立系統・遺伝的変異・祖先状態検証が追加で必要。

## 現実に最初に確かめるべき限定条件

1. **種子食者は頭花で摂食後に再び周囲に戻るか**。同一頭花内の羽化や寄生蜂出現を数えただけでは、他パッチへの次世代供給 `K,m` を識別できない。標識再捕獲・安定同位体/遺伝的親子推定・昆虫の時間的出現源トラッキングなど、対象虫と許可に応じた独立手段が必要。
2. **寄生蜂の死亡は不可逆種子損傷の前か後か**。それらが混在すればqearlyとqlateを分離する追加個体飼育・連続形態データが必要。
3. **障壁の効果は昆虫の種類と入口に固有か**。*Tephritis*、*Xyphosia*、ゾウムシや寄生蜂を一つの種子食者・天敵カテゴリに併合しない。総苞を穿孔する幼虫のホストレースと開花小花経由とは交絡させない。
4. **頭花性機能と最終繁殖量**。可視的な刺の投影、カメラ画像上の上下、昆虫の単なる到来は、実際の物理障壁でも有効送粉でもない。

## 先行研究と新規性の限界

植物構造が植食者を寄生蜂から隠す「enemy-free space」は既知の理論・実例である。Gurr et al. 2016, DOI [10.3389/fpls.2016.01794](https://doi.org/10.3389/fpls.2016.01794) は構造的隠れ場所が寄生蜂のアクセスを遮りうることをレビューする。Vanbergen et al. 2006, DOI [10.1111/j.1365-2656.2006.01099.x](https://doi.org/10.1111/j.1365-2656.2006.01099.x) は *Cirsium palustre* における植食者二種・共有寄生蜂と生息環境の違いを示すが、頭花の刺・角度・分散を直接操作した研究ではない。

**新規の検証候補は、既知のenemy-free spaceをアザミ頭花の具体的な侵入口幾何と発育段階に結びつけ、どのギルドだけが遮られ、植物個体の繁殖成功までどの方向に変化するかを実証すること**。本計算はそれを立証していない。

**結論（2026-10-08）:** 長期パッチ逆転は局所滞留・弱いパッチ間移動に強く依存する。世代間逆転という表現は単独の主張として前面に出さず、移動・頭花形質・到来圧力・充実痩果が直接観測できるまで検証候補の地位に留める。
