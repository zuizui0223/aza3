# GROW博士3年・研究主線／対立仮説／停止規則（2026-10-26）

**状態**：申請書の編集用に既存の研究計画を再編。実験実施・伊藤元己教授からの試料受領・独立したアザミ適応結果は未達。既存資料を調べたことと、仮説が成立したことは区別する。

## 核心：何を、どこまで示すのか
**中心質問**：「アザミが新たな地域へ進出する過程で頭花の向き、総苞片・刺、ディスプレイ、花色はどのように繰り返し進化し、そこでの送粉・種子食害・降雨との相互作用が現在の繁殖成績をどのように左右するか。」

- **研究A①：歴史（D1の主成果）**：既存の350核座位広域系統樹を参考骨格に、提供予定の標本・DNA・形態記録（実在すれば）と重点集団のRAD-seqを重ねて、核系統・可能な分岐年代・祖先形質・複数回の形態変化・向き×総苞の共変化を推定する。「分布進出があるから先祖返りした」とは言わない。
- **研究A②：現代の適応的機能（D2主実験、D3再現）**：新地域進出の候補と比較対象を系統上で固定後、主対象1種×2集団（暫定計50–60独立母植物、100–180追跡頭花）で、向きの非破壊操作＋shamを主軸に、総苞はまず自然変異を測る。送粉・種子食・降雨経路と充実痩果数を別々の評価量にする。次の年／条件で独立再現する。
- **研究B③：潜在的な形成能力（D3の発展）**：試料・花器官の成熟段階・集団対照が揃う1系のみ、可視花色・候補酵素・制御発現・核祖先を同一個体で比較。**再発現とF1維持は必達にしない**。
- **独創性の境界**：Moreyra et al. 2025が分岐年代・広域分布史と350核座位系統樹を公刊済み。単なる全属系統樹の再作成は新規性としない。Q1の新規性は個体・形態を結ぶ祖先形質史、Q2の新規性は頭花形態→相手別接近／真の侵入・受粉・直接損傷→最終繁殖成績の同時追跡。両者の関連だけで過去の形態が適応的選択で生じたことの因果証拠とは呼ばない。

## 真の競合仮説（望ましい結論を固定しない）
| 番号 | 仮説（支持なら） | 競合または反証となる結果 |
|---|---|---|
| A① H1a | 向き・総苞は複数の枝で繰り返し異なる組合せを形成する | 全状態差が少数の変化・祖先多型・種の誤同定で説明できる |
| A① H1b | 分布進出に対応する複数の系統で類似形態が再出現する | 現生地理だけで進出方向が未識別、既存多型保持・単一起源で足りる |
| A② H2a | 大きなディスプレイは送粉者到来と種子食者曝露をともに増やす | 頭花当たり花粉沈着・食害・充実痩果が同率では変わらない／密度希釈 |
| A② H2b | 向き×総苞は送粉者と敵の実際の接近・侵入を**選択的に**変える | 到来量のみの差、同じ入口で両者が妨げられる、敵が迂回する |
| A② H2c | 向きは食害防御より、降雨時の花粉保護に効く | 無介入の関連が消え、向きは機能に関係しない |
| B③ H3 | 見えない祖先型の機能資源が代表系で保持される | 機能資源なし／配列のみ保持／花器官発現不明／移入による導入 |

**測定で取り違えない：** 花粉沈着と来訪は別。食害頭花率（被害有頭花／登録適格頭花）と種子損傷率（直接被害痩果／観察できた痩果）は別。主結果は母植物単位の成熟・充実痩果数。柱頭採取など破壊測定が必要なら**同じ頭花内で別の標識小花**を使用し、種子収穫対象との干渉・頭花IDを監査する。

## D1（月別の決定工程）
1. **M1–2：試料条件確定**。伊藤教授の提供予定アザミについて、種名・voucher・保存方法・個体数・原産地・利用条件・DNA抽出権限・同じ標本の頭花画像を実際に確認。不足はその時点で報告。
2. **M3–4：24–48個体を目標とした技術pilot**。共通RAD座位、独立反復の一致率、欠測・倍数性・paralogとアレルdropoutを品質管理。閾値は形態結果を見ず予め設定。
3. **M5–8：適格な集団をRADで解析、広域は公刊核系統骨格と一致点・不一致点を評価**。弱い節点を単一の真の祖先枝とみなさない。
4. **M9–12：祖先形質・変化数（区間）・進化的共変化・分布史の競合・年代較正可能性をまとめ、主張可能な範囲でA①論文草稿を作成**。年代推定ができない場合は「分岐年代未解決」を明記。新規標本・形態情報が不足した場合、公刊樹への単純再当てはめは新規系統史とはしない。

## D2・D3のフィールド入口と出力
- **最初の蕾期pilot**：実際の送粉者・種子食者の存在と接触/産卵、形態変異、気象暴露、標識成功、撮影努力、site×mother分散を確認。**事前に宣言する最小意味効果とpilot分散**から、主要効果と interaction の検出可能性を判断する。
- **主要介入**：保全/許可が満たされた場合の、向きのみの非破壊操作／偽操作／自然状態。総苞の刺切除を自動追加しない。総苞との相互作用は最初は観測的条件差であり、総苞の独立した因果効果を証明しない。
- **主要評価量**：ギルド別実測接近率（録画時間分母）、産卵成立率（相手確認と蕾期を含む）、直接確認した種子損傷、花粉沈着（同花器官でも非干渉測定）、**母植物あたり充実痩果数**。
- **D3**：翌開花期・独立母植物で予め固定した主要比較を再検証。別系統へ外挿できる場合も、遺伝的に独立の変化が識別できる範囲でのみ一般化。
- **予備研究B③**：時間・同一個体の花器官が揃う場合に限る。見かけの再出現や既存葉RNAだけで「祖先経路の再活性化」と書かない。

## 失敗した場合のルート：3年を守る
| 失敗箇所 | 判定 | 進める代替案／結論の上限 |
|---|---|---|
| 供与試料未着／DNA不適合 | 受領台帳・DNA品質・許可 | 既存350座位核系統＋新規形態測定で実施可能なA①に限る。新規分子データを得たとは言わない。 |
| RAD共通座位不足・混倍数 | 重複、ドロップアウト、同型一致 | 広域をtarget-capture、RADを集団内へ分業。必要なら許可後ターゲットキャプチャーへ移行。 |
| 年代較正不能 | 元樹・ノード対応・既報年代区間 | 祖先形質と相対順序・変化数区間に限定。移住の時間や異例の進化速度を捏造しない。 |
| 反復変化が弱い／未知 | tree ensemble×state coding | 単一起源・祖先多型・系統不一致を主結果に。予想した複数の再獲得を強制しない。 |
| 種子食者が来ない | 努力時間・蕾期・昆虫同定 | 主経路を「向き×降雨／花粉保護」に変更。食害防御は未識別。 |
| 向き操作が傷・振動を起こす／許可なし | sham・安全性・保全 | 自然頭花の比較に降格して因果性を主張せず、翌年適切な別系を検討。 |
| 向き×総苞に防御効果がなく、信頼区間が狭い | SESOIとCI | **防御フィルター説の反証**。雨保護／単なる誘引／迂回を比較し主張可能な機構を残す。 |
| 食害率と充実種子数が不一致 | 同じ物理頭花・分母 | 受粉・資源・時期・頭花順位などの補償経路を検証。食害率＝雌性適応度という単純説を反証。 |
| D3再現せず／B③失敗 | 条件差の事前登録と適切な反復 | 環境依存と再現性限界を報告。B③を切り離してA①＋A②を完成。 |

**結果区分（誤解防止）**：「支持」「十分精密な反証」「代替機構の支持」「観測不足・未識別」を区別する。「p > 0.05だから効果なし」「同じ花色が再出現したから祖先形質が復活」は禁じる。
