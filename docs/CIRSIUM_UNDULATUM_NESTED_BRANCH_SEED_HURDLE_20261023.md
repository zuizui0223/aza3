# aza3 Q2｜頭花の位置差は「種子ができるか」か「できた後の量」か

**2026-10-23｜原著資料を新しく再解析した探索的結果。** West & Louda (2021) [10.1002/ajb2.1744](https://doi.org/10.1002/ajb2.1744)、USDA原表 [10.15482/USDA.ADC/1522649](https://doi.org/10.15482/USDA.ADC/1522649)（CC0）。[前回の母植物単位比較](CIRSIUM_UNDULATUM_WITHIN_BRANCH_HEAD_PLACEMENT_20261023.md)を、頭花位置番号の百位ブロック（200と210、300と310など）が一致する**枝コード群**まで絞った頑健性確認。

## 問いと新しい結論

**「枝途中の頭花は、食害が強いから種子を減らす」のか。それとも種子を1粒以上形成できる確率と、形成後の粒数を分けて考えるべきか。**

2008年に差が目立つが、もともと記録された2種類の側枝位置が揃う枝コード群は**9組・母植物7株**のみ。枝途中で良好種子の少ない組は7、逆転した組は1、同数は1。特に**2008|WR56|3**では同じ枝コード群の末端68粒、途中85粒と逆転し、両者の食害スコアは同じ0.63。したがって**同じ母植物内で7/7が負だったという平均結果を、「すべての枝で負」や「食害が一貫して強い」に言い換えてはいけない。**

| 元資料からの厳密な比較 | 2007年 | 2008年 |
|---|---:|---:|
| 対応枝コード群 | 11 | 9 |
| 対応母植物 | 7 | 7 |
| 枝途中−末端：良好種子が少ない／多い／同じ | 6／4／1 | 7／1／1 |
| 枝途中−末端：平均good seed差／組 | −5.91 | −34.44 |
| **両方が1粒以上形成** | **8** | **3** |
| **末端のみ形成** | **2** | **5** |
| **途中のみ形成** | **1** | **0** |
| **どちらも0粒** | **0** | **1** |
| 両方形成した組に限る良好種子差の平均 | −2.63 | −23.33 |
| 枝途中−末端：食害差が負／正／同じ | 5／6／0 | 2／3／4 |

母植物を独立単位として各植物内の対応枝差を平均すると、2008年**7/7株が負、株平均−40.43粒／枝コード組**（極端なWG25を除いても6株平均−25.50）。2007年の母植物平均は−8.00粒（4株負、2株正、1株同値）。ただし、この母植物平均は「記録できた対応枝コード群」に条件付けられた量で、**全106母植物**や全枝への推定ではない。

## 成功／失敗の二段階として読む

- 第1段階：原著が「よく発達し虫害が小さい」と判定した **good seed が1個以上あるか**。2008年は末端で8/9、途中で3/9。これらは同じ枝コード群の**対応した結果**であり、18個の独立な花を用いた単純な二標本検定にしない。
- 第2段階：**両方で形成された3組だけ**の粒数差は平均−23.33。ただし第1段階で選ばれた集団内の記述量であり、途中位置の純粋な資源効率・送粉効率を識別した量ではない。
- 2008年は5/9組で「末端のみgood seedがある」。その5組のうち、途中の方が元著者の食害スコアで高いのは3、同値1、低いのは1。第1段階の非対称性を**測定された食害差だけ**で説明できたとはいえない。

このデータからは、頭花の形成順、開花・成熟段階、頭花サイズ、花粉制限、母植物資源、観測打ち切り、昆虫訪花者・植食者の直接の識別ができない。**年差の原因も検証されていない。** 再生産の次世代実績ではなく、原著定義のgood seedである。

## 照合と統計境界

原USDA母植物106行、頭花323行のうち、母植物ID一致309行、処理矛盾12頭を除く解析適格297行（頂端103／側枝末端173／枝途中21）。枝途中21のうち、同じ百位コードに末端を持つ20組を採用。**2007|355|3**の途中頭花には同コードの末端頭花が記録されず、欠測をゼロで補わず除外。

原辞書は「00」は枝末端、「10」は枝末端と茎の中間と説明する。**200と210が物理的に同一本の枝に連続するという配線図や観察写真までは原表で確認していない。** 本稿の「対応枝」は同じ百位の位置コード群を表す。元著者によるコーディング規則の再確認が必要であり、実測の花序角度・総苞刺・頭花齢ではない。

母植物内の枝を独立反復としない。7母植物の符号一致に対する探索的両側exact sign p=0.015625だが、[前回の2年×3項目の事後比較](CIRSIUM_UNDULATUM_WITHIN_BRANCH_HEAD_PLACEMENT_20261023.md)のBH補正 **q=0.09375** を、新しい比較だけで家族を狭めて「有意」にし直さない。母植物再抽出の区間は記述的な不確実性であり、枝位置の因果効果の区間ではない。Treatmentは母植物単位なので、対応枝差は同一処理内の**観測的**比較にすぎない。

## aza3 LEGO／Q1–Q3 との接続

**Q2の実測**：頭花構造の位置による繁殖成果を、種子形成という段階と形成後の個数に分解する必要がある。形態×相互作用相手×資源の機能利益を次に直接測る動機となるが、現時点で「枝位置の適応」「昆虫による選択」は未証明。

**Q1**：同種・2年の頭花配置比較から、別系統への形質の進化的記憶の可搬性は結論できない。

**Q3**：既存頭花の種子形成は、失われた色素形質の遺伝的再発現とは全く異なる。antoの上流モデルにゲノム実証を誤帰属しない。

次の必要な生物測定は、野外サンプル採集許可を前提に、全母植物（位置が成立しない個体を含む）へIDを付け、枝連結・頭花齢・花冠／総苞／刺角度、送粉接触・産卵・食害、成熟充実痩果・発芽まで同じ頭花IDに結ぶこと。**今回の新規野外観測・採集は0。**
