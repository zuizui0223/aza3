# aza3 Q2｜北米アザミの実測頭花形態と独立の訪花観察を種単位で接続できるか

**2026-10-24：本物の頭花形態と実際に記録された昆虫訪花者を、独立した元データ間で安全に照合する実装。**

## 二つの全く異なる原資料

- **植物側**：Siniscalchi et al. (2023), [DOI 10.1086/724310](https://doi.org/10.1086/724310)。著者の[63端点のCirsium形態データ](https://github.com/carol-siniscalchi/cirsium/blob/c925d4af86160064448f794a9715f70b917a2786/traits/traits.csv) を元Git blob `fa127f0587b676e6e004ea121424d26069586bcb` で固定。利用するのは**頭花の向き**（直立0／下垂1）、**外側総苞片姿勢**（上向き0／開出1／反曲2）、**粘着稜の記載**（無0／有1）。別列のHummingbird/Insect送粉シンドローム分類は、形態的に定義された可能性があるため**独立な昆虫観測として使わない**。
- **訪花者側**：GloBIに収録されたiNaturalist由来の [2026-10-08確定スナップショット](https://github.com/zuizui0223/aza3/actions/runs/37743990447)。104,162関係レコードを厳格な `visitsFlowersOf`・成虫・昆虫分類パス・二名法・観察ID・地理情報で濾過し、**3,243件の固有成虫訪花観察ID／42元アザミ名**を受け入れたもの。元GloBI ZIP SHA256 `ce0513fde35d9c1be42cef87da7a6f4b262e9b4fe237ba0b78e9bf31771b58a4` を固定。外部CSVは変更しない。

どちらも**同じ植物個体・同じ頭花で撮影されたデータではない**。植物側は分類群単位の原著形態コード、昆虫側は写真等に基づく訪花の投稿記録であり、花粉付着・植食性昆虫の産卵・充実種子のデータを含まない。

## 実際に計算して分かった最重要の結果

元の2種類の独立資料をGitHub Actions [source verification run 40076670298](https://github.com/zuizui0223/aza3/actions/runs/40076670298) で**真正ファイルから再取得・再計算**した。データを架空の植物IDで結合したものではない。

| 元資料の母数と、実際のリンク可能性 | 結果 |
|---|---:|
| 北米形態原著の元の核系統端点 | **63分類群** |
| 明確に2語の二名法にできる形態ラベル | **56種名**（7端点は亜種などの多語を除外） |
| GloBIの独立成虫訪花元データ | **3,243固有観察／42植物名** |
| 元文字列による厳密な形態×訪花の種名一致 | **15種・1,010訪花記録**（全地域） |
| 北米の広い設定内に残る一致 | **15種・902記録** |
| 1種2度セル2地域以上かつ訪花記録5件以上 | **6種** |
| 同じ条件で10件以上 | **3種・852訪花記録** |
| 形態のどちらの状態にも最低3種いる比較（10件条件） | **0軸** |
| 互いに異なる頭花形態を持つ2種が、同一2度セルで各5件以上記録 | 粘着有無の**1種ペア・1粗地域のみ** |
| 形態の違う種ペアを3地域以上で比べられるもの | **0種ペア** |

10件・2地域の採用条件を満たすのは ***C. nuttallii*（112訪花／9粗地域）、*C. texanum*（41／11）、*C. vulgare*（699／61）**。3種の原著頭花はすべて**直立・外側総苞片非開出**。粘着稜は2種「有」、*vulgare*の1種「無」なので、送粉者候補の分類群比率から粘着有無の効果を推定するのは危険。

**観察の大きな偏り：** 北米内の一致902件のうち**699件（約77.5%）は*C. vulgare***。同種は北米の在来種ではなく、[米国森林局の一次種レビュー](https://research.fs.usda.gov/feis/species-reviews/cirvul)でも**外来・侵略的**と明示される。従って、現状の記録構成を「北米固有アザミの多様性を代表する」とみなすのは不適切。外来種の訪花者相を同属の進化的放散の本来の表現型−送粉相対応へ直接代入もしない。

**不足している形態が明確になった：** 元形態で**外側総苞片が開出・反曲**の種で、北米側に記録が比較的多いのは*C. edule*（5件・3地域）と*C. neomexicanum*（5件・3地域）。しかし最低10件には到達しない。**頭花下垂**をもつ*C. vinaceum*は2件・1地域のみ。この他の下垂種に観察記録が照合できない場合、**「昆虫が訪問しなかった」という0ではなく、データベースで観測・照合できていない**という意味。加えて元データが成虫**昆虫**に限定されているので、鳥による訪花と頭花姿勢との対応にはそもそも使えない。

植物の分類群を変えても同じ地域で昆虫記録がある「粘着稜」比較は、*C. douglasii*（原著粘着有）–*C. vulgare*（粘着無）の**1種ペア、2度グリッド1個**だけだった。別年・別日の可能性があるため、同時に生育する植物の選好実験や同じ昆虫の接触比較には昇格しない。

### 進めるべき実証上の順序

1. **既存iNaturalist/GloBIを無限に増やすだけでは、頭花LEGOの機能利得は検証できない。** まず現生外側形態が違うアザミの**共存し同時に開花する**個体の正しい分母を測る。対象候補には、元形態ソースで外側開出を記録した*C. edule*と*C. neomexicanum*、下垂の*C. vinaceum*のような証拠不足の形態状態を優先する。ただしこれは保全地域への採集許可ではない。
2. **Q2本体**は日本の現地適格性・保全許可を確認した*C. sieboldii*等の同一頭花で、向き／総苞姿勢・実際の刺長・昆虫の接近失敗を含む訪花・産卵・実際の有効花粉と種子まで結ぶ。個体別の表現型を測っていない北米の種ラベル同士の相関は代替にならない。
3. 63端点の鳥媒／虫媒**形態シンドロームラベル**を、GloBIの記録昆虫相の独立説明変数と混同しない。モデルを構築するには、観測者／日／地理／観察努力量／対象花数をちゃんと保持する必要がある。

今回の新しい確定結果は**「独立の相互作用観察を使った頭花形態×相手の普遍性検証は、信頼できる原資料でも支持範囲が不足する」**こと。その原因が、全体の訪花データ数不足ではなく、**原著で記述された形態状態の種別カバレッジと、外来種への記録集中**にあると特定できた。

## 照合時の安全規則

1. 植物側の名前は明示的な **`Cirsium_種小名` の2要素のみ**正確な元二名法へ直し、元資料の亜種／変種に3語以上使われた端点は**種全体の形態として合算しない**。分類異名や観察写真の元voucherも推測補完しない。
2. 昆虫側は原著の分類パスから**1つの昆虫目**が確定する成虫の明示的な訪花記録だけを昆虫目組成に使う。チョウ・ガ＝送粉者、ハチ目＝有効送粉者という自動変換もしない。成虫訪花から幼虫の種子食害を推定しない。
3. 北米元形態パネルとの初期比較には緯度18〜72°N、経度170〜50°Wという**広い座標上の探索範囲**を使う。これは植物ごとの本当の在来分布域判定ではなく、近隣で開花していたことを保証しない。
4. 種単位の探索的な記録組成を評価する最低条件を、同種の同定済み成虫記録10件以上かつ2度グリッド2地点以上、として事前固定。1種しかない状態群の「効果」を推定しない。形態状態群を比較するなら各状態最低3種、元の原著63端点を独立進化の63反復とみなさない。
5. 別状態の2種で同じ2度グリッドに**各種5記録以上**ある比較単位を数える。これは同年・同月・同じ頭花の共存証拠ではない。**全3,243件のGloBI抽出元 `event_date` は空**であり、時間の同時性も未同定として保存する。

この規則で照合可能性が不足した場合は、計数0から「頭花形態は昆虫を選別しない」とは結論せず、**データ不足による識別不能**として結果を機械的に出す。

この段階で望む**新しい生態学的主張**は「どの実測頭花状態なら、形態から定義したシンドロームに依存せず、観測された昆虫相と照合できるか」である。十分な種・地理・時間・昆虫接近の分母がない場合はそこから先の形態による相手選別の因果主張をしない。*C. discolor* 等の粘着防御利益は既存の同種実験で別途扱い、ここへデータ上の個体IDを捏造しない。
